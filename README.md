# Map Forge

A browser-based procedural fantasy world generator. You start with a whole planet on a zoomable globe and can zoom in through roads and villages to the streets and buildings of individual towns; later phases will add dungeons and battlemaps. Everything runs client-side, with no server and no account.

Stack: TypeScript, Vue 3, Vite, MapLibre GL JS. Node.js runs the tooling and the headless preview script.

## Quick start

```sh
npm install
npm run dev        # http://localhost:5173
npm run build      # type-check + production build to dist/
npm run preview -- --seed=forge --layers=fantasy,terrain --at=-57,-33,7   # headless PNGs in out/ (tiles use the first layer)
```

## Controls

| Control | Range | Effect |
|---|---|---|
| Seed | any text | Deterministic world seed. **Random** picks a new one. |
| Land mass | 10–80% (default 35%) | Share of the surface above sea level. |
| Tectonic plates | 3–40 (default 14) | Number of plates; more plates = more fragmented continents and mountain belts. |
| Erosion | 0–100% (default 50%) | Strength of stream-power river erosion. |
| Settled world | 20–100% (default 60%) | Share of the land that is the settled Old World; the rest is a sparse, tribal New World with a few Old World colonies on its coasts. 100% settles everything. |
| Detail | 512 / 1024 / 2048 / 4096 wide | Simulation grid resolution. |
| Map layer | Fantasy map (default), Terrain, Biomes, Köppen climate, Elevation, Temperature, Precipitation, Tectonic plates | Re-renders tiles without regenerating. |
| Rivers | on/off | Rivers. On the Fantasy map and Terrain layers they are drawn into the tiles (inked, clipped at lakes and the sea); on the other layers they are a vector overlay. River valleys stay carved into the terrain either way. |
| Settlements & roads | on/off (default on) | Cities, towns, villages, roads and tracks; town and village plans at high zoom. |
| Borders | on/off (default on) | Political borders: empires, kingdoms, duchies, counties and baronies, and leagues. |
| Political map | on/off (default off) | Washes each independent realm in its own colour (neighbours always differ), with duchies and then counties showing as shades of it as you zoom in, and letters every independent realm and league large with large arms. The wash fades out by zoom 11.5. |
| Place names | on/off (default on) | Lettering for realms, seas, rivers, ranges, forests, settlements, town quarters, districts, streets and notable buildings. |
| Prevailing winds | on/off (default off) | Streamline overlay of the simulated surface winds. |
| Ocean currents | on/off (default off) | Streamline overlay of surface currents, coloured red (warm) to blue (cold) by their temperature anomaly. |

The world regenerates when a slider is released or the seed changes. Hovering (or tapping on mobile) shows elevation, Köppen climate, temperature (mean, warmest and coldest month), precipitation (and how much falls in summer), prevailing wind, ocean current (at sea), biome and plate for that point. Hovering a cave or glade icon shows a preview card (or, close in, its map laid over the ground); double-click it to open its map (see **Caves and groves**). Towers, crypts, ruins and mines, and the sewer grates and catacomb stairs drawn on town plans, work the same way (see **Dungeons**). Clicking a realm's name or arms opens its details (see **Realm details**). From zoom 17, hovering a building in a town or village draws its ground-floor plan over it; double-click it (on touch screens, tap it a second time) to go inside (see **Building interiors**). The globe button switches between globe and flat Mercator views. The URL hash (`#zoom/lat/lon`) saves the current view.

## Generation pipeline (`src/gen/`)

The world is simulated on an equirectangular lon/lat grid that wraps east–west. All tunables are in physical units (km, m, °C, mm/yr) in `src/gen/config.ts`, so results look the same at every **Detail** setting.

1. **Tectonics** (`tectonics.ts`): plates are weighted, noise-warped Voronoi regions on the sphere, each rotating about a random Euler pole. A continental-crust field (plate bias + blurred noise) separates continents from ocean floor. Relative plate motion at boundaries produces:
   - convergent continent–continent collisions: wide, high ranges
   - ocean–continent subduction: coastal ranges set back from a trench
   - ocean–ocean subduction: the denser plate dives under the other, leaving a trench on one side and a single island arc, broken into separate island groups, behind it on the overriding plate
   - divergent boundaries: mid-ocean ridges and continental rifts

   Boundary ranges have a main ridge with foothills, and low-frequency noise breaks them into segments of varying height, so a range doesn't run the full length of a plate boundary. Interior ranges (Appalachian/Ural style) follow the boundaries of an older, finer plate pattern; only some of those ancient sutures survive as ranges. Sea level is then set by area-weighted quantile so the land fraction is exact, and enclosed seas larger than 25,000 km² become lowland basins.
2. **Initial climate** (`climate.ts`):
   - **Temperature** comes from latitude and the lapse rate.
   - **Wind:** a per-cell field built from the three circulation cells (easterly trades converging on the equator, poleward westerlies, polar easterlies). Low-frequency noise makes the flow meander, it turns away from steep terrain, and land friction slows it.
   - **Moisture** is carried along the wind with semi-Lagrangian advection, using fixed steps in km. Air picks up moisture over the sea and rains out over land. Lifted air condenses as it cools, which gives windward mountains heavy rain and leaves rain shadows downwind. Land returns part of its rain to the air (evapotranspiration).
   - **Rain bands** come from wind convergence: where the winds meet (ITCZ, polar front, onshore flow slowing over land), air rises and rain increases. Where they spread apart (subtropical and polar highs), air sinks and dries. The bands follow the simulated winds, so they bend around continents rather than lying flat at fixed latitudes.
3. **Erosion** (`hydrology.ts`): priority-flood depression filling and steepest-descent routing, then an implicit stream-power solver (Braun & Willett 2013) weighted by precipitation. Closed basins partly fill with sediment.
4. **Final climate**: recomputed on the eroded terrain, now including **ocean currents** (`ocean.ts`):
   - **Wind-driven gyres:** surface water drifts with the wind and turns into boundary currents where it meets a coast. Subtropical gyres run poleward along western ocean boundaries (warm) and equatorward along eastern boundaries (cold, with upwelling). Subpolar gyres reverse both, which warms high-latitude west coasts. Narrow seas form only weak currents.
   - **Sea temperature:** carried along the currents and relaxed back toward the latitude baseline.
   - **On land:** the wind carries the sea-temperature anomaly inland. Air over cold water is stable and rains less, which produces foggy coastal deserts.

   **Seasons:** the climate is simulated for northern summer and northern winter.
   - **Temperature swing:** the warmest and coldest month differ from the mean by an amount that grows with latitude and with continentality (how far the wind has travelled from the sea), so coasts are mild and interiors are extreme.
   - **Seasonal rain:** the wind bands and rain belt shift toward the summer hemisphere, and a monsoon term turns winds onshore in summer and offshore in winter. Moisture transport runs once per season to give summer and winter precipitation; annual precipitation is their mean.
   - **Köppen–Geiger** (`koppen.ts`): the full set of 30 classes (Af…EF), from mean, warmest- and coldest-month temperature and seasonal precipitation, using the standard map colours. On test seeds the land shares come out close to Earth's: about 19% tropical, 27% arid, 18% temperate, 24% continental and 12% polar.
5. **Rivers & lakes** (`rivers.ts`, `river-index.ts`): flow is accumulated, weighted by precipitation. River polylines are split by discharge class, jittered, and Chaikin-smoothed. Lakes form in deep basins only where precipitation is high enough to keep them filled.
   - A shared **river index** bins the segments for fast distance queries. Widths taper smoothly downstream (each feature spans one discharge doubling, so its width grows from one class to the next along its length).
   - **Meanders:** distances to a river are measured from a point displaced by a smooth noise field (domain warping, 9 km down to ~0.5 km wavelengths), so the straight coarse courses bend the same way in the tiles, the terrain sampler and the town plans.
   - **Valleys:** within a floodplain that widens with the river, the sub-grid detail relief fades out, the floor sinks a few metres toward the banks and the channel is cut below them, so rivers never climb over noise ridges.
6. **Biomes** (`biomes.ts`): a Whittaker-style classification from annual temperature and precipitation, refined by terrain and water:
   - **Ice:** ice caps where summers stay below freezing, or glaciers where cold summers meet heavy snowfall.
   - **Treeline:** trees need a warmest month of at least 10 °C, so cold, dry land stays tundra.
   - **Altitude zones:** alpine meadow above the treeline, montane forest on high wet slopes.
   - **Wetlands and marshes** on flat floodplains and lakeshores.
   - **Mangroves** on hot, wet, low coasts.
   - **River valleys / oases:** green corridors where large rivers cross dry country.
   - **Salt flats** in closed basins too dry to hold a lake.
7. **Streamlines** (`streamlines.ts`): evenly spaced streamlines with arrowheads, traced through the wind and current fields for the overlays.
8. **Old World and New World** (`oldworld.ts`): settlement spreads from a heartland (temperate, watered land of the largest landmass) by travel cost: over land, dearer through mountains, and across the sea at six times the cost, so a continent fills before the next is reached. The first share of the land to be reached (the **Settled world** slider) is the Old World. Other landmasses then go wholly one way or the other, by which side holds most of them; only the heartland's own landmass may be split, along a frontier that tends to follow its ranges. Because whole landmasses go together, the actual share can differ from the slider by several points. The rest is the **New World**: no cities, tribal towns and villages far apart, New World cultures, tribal realms, and a few colonies of Old World realms on its coasts.
9. **Settlements & roads** (`settlements.ts`):
   - **Habitability:** each land cell is scored on mild temperatures (warmest month ≥ ~10 °C, not too hot), enough rain, low elevation, gentle slope and biome. Rivers, sea coasts and lakeshores add a bonus.
   - **Cities and towns** are founded greedily on the best sites. In the Old World cities are at least 280 km apart and any two towns or cities 65 km apart (about 11,000 towns and 600 cities on a 1024-wide world, settling 20 seconds or so). In the New World there are no cities, and towns are at least 190 km apart: these are **tribal towns** (about half the size, unwalled, built as large villages). Population grows with site quality; cities and larger towns are walled.
   - **Colonies** (`colonies.ts`): about one New World coastal town in eleven (three to fourteen in all, at least 400 km apart) becomes a colony, a fort or a trading post of the seafaring Old World culture whose coast lies nearest (no one culture founding more than half of them), so each power's colonies cluster on the shores facing it. Colonies take their founders' culture and are named after a home town ("New Ashford"), as forts ("Fort Valcia"), landings and posts, or as ports. They are built as Old World towns, and the villages round them are ordinary villages.
   - **Placement:** river towns sit on the river line, offset to one bank so the river runs through the town. Coastal sites are nudged onto land at full shoreline detail (`detail.ts`, which samples the same sub-grid terrain as the tiles).
   - **Roads** link neighbouring settlements (a relative-neighbourhood graph: major roads between cities, minor roads between towns). Each road is routed by A* over the grid, with costs for slope, biome (wetlands, rainforest and ice are slow) and bridges. Reusing an existing road is cheap, so routes merge into trunk roads. Roads are smoothed and stop at the edge of each town plan.
   - **Fine layout:** the grid route only fixes a vertex every ~39 km, so each stretch between two vertices is laid out again on a strip of lanes either side of the straight line (3 km steps and up to 8 km off the line for major roads, 5 km steps and 7.5 km for minor ones). A dynamic programme picks the cheapest path over the sub-grid terrain the tiles draw: it bends round hills and spurs, keeps to valley floors, runs beside rivers (cheaper near a bank, a toll to cross that grows with the river) and wanders a little across open ground (a smooth noise field). The road moves at most one lane per step, so it stays smooth. Stretches are cached by their end points, so roads sharing part of a route share the same line. After smoothing, a slight hand-drawn waver is added and the line is simplified (Douglas–Peucker, 60 m).
   - **Keeping roads on land:** the grid route only knows 39 km cells, so at full detail it can cut across bays, lagoons and lakes. Near water (low land, coasts and lakeshores) each road is resampled every 600 m, and every 150 m around wet samples; short wet stretches are pulled onto the nearest shore and eased, and any remaining open-water crossing longer than 750 m (counting islet-hopping across an archipelago as one crossing) breaks the road at the shore. Short crossings stay as bridges or causeways, and rivers are always bridged. Roads that meet a town in the water start at the shore instead.
10. **Names & labels** (`src/names/`, `features.ts`):
   - **Cultures** (`cultures.ts`, `culture-map.ts`): sixteen naming cultures. In the Old World: Anglo, Norse, Latin, Celtic, Elvish, Desert, Slavic, Dwarven, Southern, Steppe, and three East Asian-inspired cultures: **Sinic** (Chinese-inspired: Beizhou, Lin'an-like names; rivers "the X He", mountains "the X Shan", islands "X Dao"), **Japonic** (Japanese-inspired: Takamoto, Kawasaki-like names; "X-gawa", "X-san", "X-jima"; coastal and island-loving) and **Koreanic** (Korean-inspired: Gwangju-like names; "X-gang", "X-san", "X-do"). In the New World: **Jungle**, **Woodland** (forests and prairies of the temperate north) and **Highland** (high mountain valleys and plateaux: cordilleras, altiplano, "X-cocha" lakes). Each has syllable sets, compound roots and suffixes, prefixes and its own terms for features (Fjord, Wald, Bahr…). Culture hearths at least 1,200 km apart are chosen by climate suitability (New World hearths only from the New World cultures, Old World hearths only from the others) and spread by distance, with mountains and seas acting as borders, and a heavy toll for crossing between the Old and New Worlds, so names change from region to region.
   - **Name bank** (`names.ts`): deterministic per world seed and key, with duplicate avoidance for world features. Each culture has large syllable and compound sets (several thousand to over 15,000 possible names each) and mixes its forms (syllables, compounds, a root with a plain ending, a syllable with a compound suffix, glued and two-word prefixes such as Aber-, "Stara " or "Castra ", the two-word ones for settlements only); seams that read badly (four consonants in a row, a chunk said twice) are drawn again.
   - **Villages, caves and glades** are named one by one as their 1° block is generated, so they cannot be checked against the whole world; instead no two in the same block share a name (a repeat draws again), and the large sets keep repeats between neighbouring blocks rare (in a 13° × 13° test area, about 1 nearby repeat per 100 places, down from about 1 in 6).
   - **Water bodies:** oceans (far from land), seas, inland seas and lakes (enclosed water by area), and gulfs, bays and bights found by casting rays from the coast to measure how enclosed the water is. Straits and channels are narrow passages with open water on both ends; they get a line label along the passage.
   - **Land:** continents, islands and isle groups; mountain ranges (with their highest peak and height), hills, forests, deserts, marshes and plains from smoothed biome regions (each land cell also records which of these it lies in, for the location title). Realms come from the political map (see **Realms, arms and the location title**).
   - **Close-zoom water lettering:** a water body keeps its main label until it spans about one screen; from then on it is lettered from a lattice of anchors fixed in Web Mercator space (a few per screen, one lattice per whole zoom band), so a lake, bay or sea stays named while it is in view. On the open sea each name holds a territory (a Dijkstra weighted by the feature's reach, so a bay keeps its own water against the surrounding sea). Anchors deep in the water are kept; near the shore the label's footprint is tested against the coastline as the tiles draw it at that zoom. Narrow water falls back to the anchors along its middle. Lettering continues to zoom 8 for oceans, 10 for seas, 11 for gulfs and inland seas, 12 for bays, bights and straits, and 13 for lakes.
   - **Lines:** rivers are named per system (the main stem keeps one name to the sea), major roads ("the X Road", "the King's Road"). Elongated regions get curved line labels along their main axis.

## Rendering (`src/render/`, `src/worker/`, `src/world/`)

- The map is MapLibre GL with the globe projection. A custom `world://` protocol serves raster tiles that a pool of Web Workers renders on demand. One worker generates the world, then shares it with the rest.
- Tiles sample the grid with bicubic interpolation and add **fractal sub-grid detail**: more noise octaves as you zoom in, rough at coastlines and ridged in mountains. Coastlines and ranges keep showing structure down to ~10 m/pixel, and tiles stay consistent across zoom levels.
- Raster tiles go to zoom 17 (overzoomed beyond).
- Hillshading uses zoom-dependent vertical exaggeration. Terrain colour blends domain-warped biome colours with rock, snow (which needs both cold and enough precipitation) and sea ice.
- **Fantasy map** (`fantasy.ts`) gives a hand-drawn atlas look, inspired by Watabou's Perilous Shores:
  - Land is drawn as parchment tinted by biome, with soft sepia hillshading, snow and paper grain.
  - The sea is pale blue-grey, darkening with depth, and coastlines are inked.
  - Concentric ripple lines follow each coast. They come from a chamfer distance-to-shore computed over a 16 px tile margin, so they line up across tile edges.
  - Map symbols are placed on a jittered grid anchored in global pixel space and drawn back-to-front:
    - mountains (hatched, with snow caps where cold), hills
    - round deciduous trees or conifers, by forest biome
    - marsh tufts
  - Symbols are deterministic per seed and zoom. Mountains and hills are drawn up to zoom 11; trees and marsh tufts continue to the deepest tiles, growing a little and thinning out so forests still read as forests. Symbols keep off rivers and the fine shoreline.
  - **Rivers** are drawn into the tiles: a single ink-blue line while thin, then a pale channel between inked banks (with a ripple line inside broad rivers). They never get thinner than a zoom-dependent minimum, grow into their true width at close zoom, show only the largest rivers on the globe, stop at lakes, and open into the sea without an inked coast across the mouth.
  - **Contours** from zoom ~9: an interval that halves with each zoom (200 m at zoom 9 down to 2.5 m), every fifth line darker, fading out where lines crowd together. From zoom ~11.5 steep ground gets a rock stipple.
- **Lettering** (`components/label-style.ts`) uses IM Fell English (roman, italic and small caps, SIL OFL, bundled in `public/fonts/` and rendered locally through MapLibre `font-faces`, so no glyph server is needed). Labels appear by rank and zoom: realms and oceans on the globe, seas, ranges and forests regionally, lakes and smaller rivers closer in; water names are italic blue, regions are spaced capitals, settlements are small caps. Land, settlement and town lettering is drawn 20% larger than water names, on a firmer, more opaque halo, so it stays readable over forests and hatching.
- On the analytic layers rivers are a GeoJSON line layer whose width scales with discharge and zoom, growing into their true width (from ~12 m upstream to a few hundred metres on big rivers) at high zoom. The tile URL carries a river flag (`world://gen/layer/r|-/z/x/y`). Wind streamlines are a GeoJSON line layer drawn with a transparent-to-white gradient.

## Villages and town plans (`src/towns/`)

Everything below world scale is generated on demand in a dedicated web worker (`manager.ts`, `worker/towns.worker.ts`), so the map never stalls. It is deterministic, so nothing changes as you pan away and back. Each plan samples a local height and water grid (`terrain.ts`) at full terrain detail. The grid drives slope-aware layout and shorelines, and draws contour lines whose interval adapts to the relief.

- **Villages** (from zoom 7.5) are placed per 1° block on a jittered ~13 km grid. Placement uses the same habitability score, at full terrain detail, plus bonuses near roads, rivers and coasts. Each village gets a winding track to the nearest road, town or village. Villages come in several kinds, chosen from the site:
  - **Mining camps** in mountains (with enough summer warmth to work).
  - **Logging camps** in forest biomes.
  - **Fishing villages** where there is sea or a lake within ~8 km; the village moves onto the shore.
  - **Keeps** on high ground, climbing to the local summit, and occasionally guarding a road in the lowlands.
  - **Monasteries**, more often in the hills, on a level terrace or knoll above the surrounding ground.
  - Otherwise, **farming villages**.
  - **New World villages** are fewer (about two in five of the candidates are kept) and are **tribal villages**, except within 60 km of a colony, where villages are of the Old World kinds. A tribal village (and a New World tribal town, which is built the same way at a larger size) has an open dancing ground with a council house at its heart, longhouses in rings round it with their long sides to the centre, round lodges and drying racks between, a palisade (open at the trails) just outside the houses of the larger ones, and garden plots and forest beyond. The New World has no keeps, monasteries, towers or crypts, and only the odd ruin.
  - **Slope-aware sites** (sampled at full terrain detail, ~60 m): mining camps need real relief and sit on workable ground at the foot of the steepest rise within ~1.5 km (none on flat plateaus); farming villages and lowland keeps move to the flattest ground within ~900 m and are dropped if it is all steeper than 16%; logging camps avoid slopes over ~35%.
- **Markers:** cities show from the globe view, towns from zoom 5, villages from zoom 8, coloured by kind. They fade out as the plans fade in.
- **City and town plans** (from zoom 11.5, `city.ts`) follow [Watabou's Medieval Fantasy City Generator](https://watabou.github.io/city-generator/):
  - **Layouts** (`layout.ts`): each city and town gets one of five layouts, chosen when the world is named from its culture, local relief, river and coast (deterministic per seed); the hover panel shows it.
    - **Round town:** Watabou's sunflower spiral around one market.
    - **Planned grid:** a Roman castrum or bastide on a rotated, slightly sheared lattice with a squared-off core and straight streets; lots are cut at right angles, and the lattice loosens into old field boundaries further out. Most common in Latin and southern cultures, and on flat ground.
    - **Ribbon town:** stretched along the river, shore, valley or through road, with two rows of wards either side of a gently bowed high street.
    - **Hill town:** an uneven spiral (wards of mixed sizes) with a lobed outline; steep ground is kept out of the core much more strongly and streets wind with the contours. Most common on rough ground and in dwarven, Celtic, Elvish and Slavic cultures.
    - **Twin town:** two cores grown together, on opposite banks when a river runs through (big cities only), each with its own market, joined by a Bridge Street.
    The direction a town follows comes from its local ground: the river through it, else the shore, else the through road, else the contours.
  - Wards are Voronoi patches on a sunflower spiral (relaxed once), sized from population.
  - The wall follows the outline of the inner patches, with towers. Gates face the incoming roads.
  - Main streets run from each gate to the central plaza. Roads out to the country bridge rivers but never cross more than 150 m of sea or lake; they go round a bay instead, or are left unbuilt.
  - Special wards: a temple beside the plaza, a citadel with its own wall and keep on the wall's edge, and parks.
  - Wards are paved (cobbles inside the walls, beaten earth in the suburbs), so the gaps between blocks read as streets and alleys.
  - Wards are cut into small blocks (about two lots deep) with an alley (2.8 to 4.2 m) at every cut, so no block is walled in by its neighbours; contour terraces on slopes are crossed by alleys too. Blocks are then cut into terraced buildings by recursive lot cutting. Every house reaches the block edge (a street or alley); the backs of the blocks are yards (kept 3 m back from the water, and left out on harbour quays and beside piers, where only warehouses stand, clear of the pier ends). Slivers, scraps and triangles too thin to build on are left as yard.
  - Suburbs are small blocks with lanes between them: houses front the lanes, gardens fill the backs, and blocks away from the road stay as meadow.
  - Outside the walls are suburbs along the roads, then fields with furrows, orchards and meadows.
  - Sea, lakes and rivers (at their true width) carve the plan; streets crossing a river become bridges.
  - **Terrain:** the walled core grows onto the gentlest nearby ground. Street routing penalises steep grades. On slopes, blocks are cut into terraces along the contours, and ground too steep to build on is left wooded. The citadel and temple take the high ground.
  - **Harbours** (`harbour.ts`): along the waterfront, piers (some with T-heads) reach out to open water, with boats moored alongside. Shore wards become warehouses, cities get a lighthouse and ships at anchor, and river towns get short jetties.
- **Fitting plans to the ground** (`ground.ts`): every plan gets a usable-ground test built from its local terrain grid (distance to water by chamfer transform, slope, and the exact shoreline near the water).
  - **Barrier seeds:** field Voronoi diagrams get extra seeds just past the edge of usable ground (shores, river banks, steep crags) whose cells are discarded, so the neighbouring fields end along the shore in short irregular steps, as on a hand-drawn map.
  - **Fitting:** fields, meadows, yards, paving, parks, plazas and the citadel are densified, and each vertex is pulled in to the last usable point on its ray from the centre (marched outward in steps that stride by the distance to water), so inlets and ponds reaching into a polygon are cut out too; vertices end on usable ground (at least 4 m from water for fields), with inward-only smoothing and a slight hand-drawn wobble; furrows are clipped to the fitted outline. Buildings and lots are kept only if every corner is on dry, workable ground.
  - **Terraces:** on gentle slopes (6–14% in villages, up to 20% around towns) fields are cut into strips along the contour, with furrows following it.
  - **Hedgerows:** some fields and meadows get a dotted hedge outline.
  - **Walls** are walked in short pieces, so they stop at the shore with a tower instead of crossing a bay between two corners.
- **Village plans** (from zoom 12.5, `village.ts`, shared pieces in `kit.ts`) follow [Watabou's Village Generator](https://watabou.github.io/village-generator/). Buildings stay off ground steeper than 35% and turn to run along the contour on hillsides; fields on slopes over 14% become pasture, and over 25% are left wooded. Each kind has its own layout:
  - **Farming:** winding lanes from each track to a common centre with side lanes, houses facing the lanes (densest at the centre), a chapel in larger villages, Voronoi fields with furrows cut by the lanes, and trees in clumps and gardens.
  - **Fishing:** houses crowd down to the shore, with jetties, moored and beached boats, paths to the water, and a few fields inland.
  - **Logging:** a clearing in dense forest with a sawmill (on the river bank if there is one), stacked logs, stumps and a few cabins.
  - **Mining:** adits up the slope with cart tracks, spoil heaps, a smelter and huts.
  - **Monastery:** a walled compound with a church, a cloister around a garth, ranges, vegetable beds and an orchard, surrounded by fields.
  - **Keep:** a ringwork on the hilltop with a ditch, a wall with towers and a gate, a keep tower and hall, and a hamlet along the approach.
- **Names** (`naming.ts`): every settlement and village has a name in its culture (keeps, abbeys, mines and camps get fitting forms such as "Castle X" or "X Priory").
  - **Quarters** grow over the ward adjacency graph from spread-out seeds and are named after what they hold (Old Town, Castle Quarter, Harbour Quarter, Temple Quarter, Market Quarter, the Heights, gate quarters, craft quarters); suburbs are named after their gate.
  - **Districts:** the market, temple (dedicated to a named deity), citadel, garrison, harbour, parks and graveyards are labelled.
  - **Garrison and graveyard:** walled cities and towns over 2,500 people get a garrison ward with barracks and a drill yard by the citadel or a gate; some cities turn a park or wall ward into a graveyard with a hedge and rows of graves.
  - **Streets:** main streets are named (High Street, gate streets) and roads leaving town are named by direction.
  - **Notable buildings** get a role and a label: inns and taverns (with generated signboard names), moot hall, guildhall, library, smithy, bakery, apothecary, pawnshop, tailor, butcher, stables, bathhouse, chandlery and fishmonger; villages get an inn, smithy, chapel and churchyard, mill, sawmill or smelter. Labelled buildings are tinted on the plan.
- **Styling** (`components/map-style.ts`): plans are vector layers drawn in true metres (each feature carries its pixels-per-metre at zoom 20). Roads and streets share one width expression, so world roads join the plan roads seamlessly. The map zooms to 20 (~0.15 m/pixel).

## Building interiors (`src/interiors/`)

Every building on a town or village plan has a deterministic interior in the manner of [Watabou's Dwellings](https://watabou.github.io/dwelling.html), generated on demand from its footprint, its context and the world seed (`dwelling.ts`).

- **Tagging:** plan buildings carry an id, their settlement, tier and context (ward kind in towns: ward, rich, harbour, suburb, farm; or the village kind) and, where known, the direction of their street front (the lot edge on the block's street, the nearest road, or the village lane).
- **Grid:** the footprint is laid on a 1.5 m (5 ft) grid turned so the street front is at the bottom. Convex footprints (nearly all lots) keep their true outline: the plan is clipped to it and its edges are the outer walls, so slanted and triangular lots keep their shape. Furniture and stairs stay on whole cells.
- **Type:** cottage, farmhouse, town house, mansion, warehouse, temple, keep, hall, storehouse, mill, monastic range, cabin or miner's hut, from the building's use and context. Labelled buildings use their role instead: inns and taverns (taproom, kitchen, guest rooms), civic halls, libraries, barracks, stables and bathhouses get their own programmes, and shops put the matching trade room on the street. The view's title shows the building's name. The type sets storeys (with storey heights), the chance of a basement, and the roof (gabled on rectangles, hipped otherwise, flat with battlements on keeps).
- **Rooms:** a binary partition of the footprint shared by every storey, so walls line up floor to floor. Each floor's programme (for a town house: hall, a shop, workshop, smithy, bakery or taproom on the street, kitchen at the back, pantry, parlour; bedrooms and a landing above) is assigned to the partition by preference (the stair, front, back, large, small). Temples get a nave, sanctuary and vestry, and keeps a guardroom, great hall, lord's chamber and dungeon cells. Cellars are one vault.
- **Stairs:** one stairwell through every floor (a ladder to cottage lofts, a spiral stair in keeps), placed under the ridge when there is an attic. The attic covers the cells with at least 1.7 m of headroom under the roof.
- **Doors and windows:** a spanning tree of doors from the entrance (or stairwell) plus the odd extra door, a front entrance on the street side and sometimes a back door; windows along outside walls with piers between them (front and back only in terraced town houses, gable ends in attics, arrow slits in keeps, none underground).
- **Furniture** by room: beds, chests, wardrobes, hearths and ovens on outside walls (with chimneys above), tables with chairs, counters, workbenches, shelves, bookcases, barrels, crates and sacks, pews and an altar, tombs in a crypt, straw in the cells.

Views (`render.ts`, `building.ts`, `components/DwellingView.vue`):

- **Hover preview:** from zoom 17, the ground floor is drawn into an image placed over the building's footprint on the map.
- **Dwelling view:** double-click a building (or tap it twice) to open a full-screen view with a tab per floor (basement, ground floor, upper floors, attic or loft) and an **Exterior** tab. Plans are inked in a hand-drawn style with a 5 ft grid, room labels, a north arrow and a scale bar; Labels and Grid can be turned off, and **Download PNG** saves the current view for use as a battlemap. The exterior is an isometric drawing: timber-framed or stone walls with the plans' windows and doors, gable ends, the roof (thatch, tile, slate or shingle by type) shaded by slope, and chimneys over the hearths. **Leave building** or Esc returns to the map; the arrow keys change floors.

## Realms, arms and the location title

- **Political map** (`gen/politics.ts`), built from the bottom up after naming, in five tiers:
  - **Baronies:** every city and town seats a barony over the land nearest it by travel cost (a Dijkstra from all seats at once, cities reaching further). Climbs and high ground, crossing a big river (order 5 and up) and the sea (impassable) all count, so borders follow ranges and rivers. Land more than ~300 km (towns) or ~420 km (cities) of travel from any seat stays unclaimed. A barony seated in a city is styled a City (with a Lord Mayor, Podesta, Wali or the like). Keeps and monasteries, which are placed later with the villages, are named in the location title as baronial holdings and abbey lands within their barony.
  - **Counties** gather baronies around the larger seats at least ~95 km apart (about two or three baronies each); **duchies** gather counties around the strongest seats at least ~300 km apart (a duchy needs two counties); **kingdoms** gather duchies, and the counties and baronies left between them, around duchy seats ~600 km apart; **empires** are rare: two or three in the Old World, formed around the greatest kingdoms (by estimated people, weighted towards Latin, desert and Sinic peoples, and of different peoples where possible) that can gather at least three realms, two of them kingdoms, and perhaps one in the New World (most likely among Highland peoples). Realms of the Old and New Worlds never mix. In the Old World of a 1024-wide world the median barony is about 7,600 km², county 19,000 km², duchy 140,000 km² and kingdom 530,000 km² (France is about 550,000 km²). Each liege claims by the same travel cost, now across some sea and with a toll for crossing into another culture at the higher tiers; each vassal goes wholly to the liege that reaches its seat.
  - **Independent realms at every tier:** whatever no liege gathers stands alone, and some stand apart by choice: **city-states** (cities of 6,000 or more, most often in the south, sometimes with the towns within ~110 km as their territory), **prince-bishoprics, abbacies and imamates** (a few counties held by the church), and **grand duchies** (likelier among southern, Latin, elvish, dwarven, jungle and steppe peoples; rare among Norse, Slavic and Celtic peoples, who keep to kingdoms). On a 1024-wide world this gives about 5,000 baronies, 2,300 counties, 500 duchies, 110 kingdoms and 2 or 3 empires, with kingdoms the commonest independent realm (about 80, beside some 85 city-states and 60 others).
  - **Governments:** independent realms of duchy size and up may become a **republic** (above all in the south, then among Latin, Anglo and dwarven peoples), a **theocracy**, or, for island realms and realms spread over several landmasses, a **thalassocracy** (Thalassocracy, Sea Kingdom, Admiralty, Maritime Republic).
  - **The New World** is tribal: its towns seat bands, gathered into chiefdoms, tribes, nations and (rarely) an empire, styled by culture: Woodland (the X Band, X Clan, the X Tribe, the X Nation; Headman, Chief, Paramount Chief, Great Chief), Highland (Valley of X, Lordship of X, the X Realm, Empire of the X Sun; Lord, High Lord, Sun King, Child of the Sun) and Jungle (City of X, Kingdom of X, the X Overkingdom; Holy Lord, Overking, Great Speaker). Woodland nations band readily into confederacies (the X Confederacy, under a Council of Chiefs). Land beyond the towns is named in the title as the tribal lands of the woodland, highland or forest peoples.
  - **Colonies** are held from overseas: each colony town's barony sits under a colony (Colony of X under a Governor, the Garrison of Fort X under a Commander, the Trading Post of X under a Factor), held directly by the largest Old World realm of its founders' people (or, failing one, the nearest), whose colour it takes on the political map and whose people and land it adds to.
  - **East Asian styles:** Sinic baronies and counties are counties and prefectures (Magistrate, Prefect), duchies provinces (Governor), empires dynasties ("the X Dynasty", "Middle Kingdom of X"); Japonic fiefs, domains under a Daimyo, provinces under a Shugo, and shogunates under a Shogun; Koreanic hyeon and gun (Magistrate, Gunsu), provinces ("X-do") and kingdoms.
  - **People:** every unit estimates its people from its land: town-dwellers plus about 8 country people per km² of fully habitable land in the Old World (1 in the New), weighted by biome (grassland, temperate forest and river valleys in full, savanna and shrubland at 60 %, boreal forest a third, deserts and tundra hardly at all). The title and search show it ("about 12 million people"), with the town-dwellers in the hierarchy panel.
  - **Leagues and confederacies:** three or more small independent neighbours (city-states, free counties, duchies and republics within ~650 km) may band together, most readily in the south (the Amphictyony of …, the … League), among Norse (Hanse), steppe and Celtic peoples (Confederacy). Members keep their own rulers and arms; the league has a council (Synedrion, Allthing, Kurultai, Diet, Council), a seat, arms of its own, a name on the map and a dashed blue-green line round the union.
  - **Styles and rulers** follow the culture and tier: Barony, Herad, Timar, Volost, Tuath, Deme or Ulus; Earldom, Jarldom, Beylik, Zhupa, Cantref or Archonate; Duchy, Principality, Emirate, Voivodeship or Khanate (Grand Duchy for some independent duchies); the culture's kingdom styles; Empire, Imperium, Caliphate, Khaganate or High Kingdom. The ruler follows the style (a Sultanate has a Sultan, a Herad a Hersir) or the government (a Doge, an Archon, a Prince-Bishop, an Imam, a Thalassarch). Kingdom names drawn from a culture's `realm` list skip the styles that now belong to a government or another tier (republics, leagues, empires, counties, duchies).
  - Worlds wider than 1024 work out realms on a 1024 × 512 copy of the grid (realms are hundreds of km across, and the borders are smoothed anyway).
- **Borders** are traced along the grid between cells of different realms. Within a realm each line is drawn once at the highest level that differs; between independent realms it is drawn at the higher of the two realms' levels (at least a duchy's line). Lines are relaxed out of their staircase (Laplacian smoothing), rounded (Chaikin) and simplified. Empire and kingdom borders are inked dash-dot and dashed over a soft red wash; duchy borders appear from zoom 4, county borders (dotted) from zoom 6, barony borders (fine dots) from zoom 8; league borders are long-dashed in blue-green. Realm names are lettered in red small capitals (empires from zoom 1.4, kingdoms from 2.9, duchies from 5.2, counties in italic from 7.2, baronies from 9.4); leagues in blue-green italic from 2.6. Independent small realms are lettered a size up (a city-state like a duchy, an independent duchy like a kingdom), and every independent realm, kingdom, empire and league carries its arms above its name.
- **Heraldry** (`heraldry/arms.ts`, `heraldry/draw.ts`): a shield shaped by culture (heater, round, kite, French or Spanish); a field of a metal (Or, Argent), a colour (Gules, Azure, Vert, Sable, Purpure, Tenné, Sanguine, Celeste) or a fur (Ermine, Vair); plain, divided (per pale, fess, bend, bend sinister, saltire or chevron, or quarterly) or patterned (paly, barry, chequy, gyronny); an ordinary (fess, pale, bend, chevron, cross, saltire, chief, pile, pall or bordure); and one, two or three charges (mullet, crescent, roundel, lozenge, tower, crown, fleur-de-lis, key, tree, sun, cross pattée, anchor, lymphad, sword, hammer, axe, eagle displayed, wheel, bell, hunting horn, estoile, heart, acorn), keeping the rule of tincture. Charges on a divided field are counterchanged; patterned fields carry theirs on a chief. Each culture favours some charges (dwarves hammers and axes, Norse ships and axes, Slavs eagles), and governments too (theocracies crosses and keys, sea realms ships and anchors, city-states towers and keys, leagues several charges). Arms descend: a vassal keeps its liege's field and colours with a new charge, reversed colours or an added ordinary; a junior house (a barony under its county, a county under its duchy) adds a bordure or label; a realm and its seat share arms; empires are crowned. Towns take arms derived from their barony's. Each comes with its blazon ("Barry of eight Vert and Or, on a chief Argent three suns Sable").
- **Emblems of other cultures** (`STYLE_BY_CULTURE` in `heraldry/arms.ts`, drawn in `heraldry/draw.ts`): not every people bears a European shield. **Woodland** realms bear a painted round hide shield with a laced rim and five hanging feathers; **Highland** a square emblem with a border of small squares and a stepped cross with the charge in its heart; **Jungle** a rounded glyph block with a stepped-fret band below and a dot for each charge; **Japonic** a round mon, one colour on another within a ring (three charges wheel about the centre, as in a triple tomoe); **Sinic** a square seal with a double frame and key-fret corners; **Koreanic** a banner on a pole with a spear finial, fringed with flame points; **Desert** a round blazon of three bands with the charge on the broad middle one; and **Steppe** a brand mark (tamga) on a disc hung with horsetails, built stroke by stroke from the arms' seed. These emblems take no ordinaries or furs, and only some divide their field (hide shields halved or quartered, glyphs and banners halved). Their peoples favour their own charges, among them five new ones: the tomoe, the feather, the bird volant, the serpent and the cloud. Vassals difference their liege's emblem by a new charge or swapped colours (a tamga gains a stroke of its own on its liege's mark), junior houses by a coloured ring or mark, and empires take a gold frame in place of a crown. Arms descend in their liege's form, so a colony keeps its founders' European arms. The blazon names the form first ("A mon: Celeste, a blossom Argent").
- **Political map** (`world/political.ts`; the **Political map** checkbox): raster tiles drawn on the main thread from the political grid through a `politics://` tile protocol. Each independent realm gets a colour from a twelve-hue watercolour palette with no greens or yellows (they would vanish into the map's meadows and deserts), chosen largest realm first as the hue furthest from its neighbours' hues (league members lean to their league's hue where it stays clear of their neighbours). Up to zoom 5 a realm is one flat colour; from zoom 5 its duchies, and from zoom 8 its counties, show as lighter and darker shades of it. Cells along a realm's edge are washed deeper, and colours are blended between grid cells, so edges are soft rather than stepped. The wash is strongest zoomed out (85 %) and fades as you zoom in (55 % at zoom 6.5, 25 % at 9, gone by 11.5), leaving the borders and the internal divisions' labels. While it is on, every independent realm is lettered larger in dark small capitals (larger still for larger realms) under its arms drawn at about twice the usual size, leagues likewise in blue-green italic; these replace the usual empire, kingdom and league labels and the labels of independent small realms.
- **Location title** (`components/LocationTitle.vue`): a cartouche at the top of the map names where the map centre is, at the scale you are looking at: the empire (or the highest realm there) when zoomed out, the kingdom from zoom 4.3, the duchy from 6.3, the county from 8.3 and the barony from 10, with its arms, its ruler and seat, its kind of government (for independent realms and kingdoms), its vassals by tier ("5 duchies, 2 counties", or a league's members), the land region it lies in, and the realms above it (and the league) as a breadcrumb with small arms. From zoom 11 it names the city, town or village under the centre (with population, layout and the realms it seats; for keeps and monasteries, the barony they belong to); over the sea it names the sea, in unclaimed land the wild region. Click its name or arms to open the realm's details (a breadcrumb opens that liege); the arrow beside it lists the whole hierarchy with larger arms, government, area, people, vassals and blazons, each row opening its realm. Realms are searchable too, by name or kind ("league", "republic", "city-state"), and choosing one opens its details as the map flies there.

## Realm details (`src/lore/`, `components/RealmView.vue`)

Click a realm's name or arms on the map, the location title, or a realm in search to open a panel beside the map (a sheet from the bottom on phones) about that realm, at any tier from barony to empire, and for leagues. Every realm named in it opens in turn; **Back** returns, **Show on map** flies there. All of it is seeded from the world, so a world always tells the same story. The world's lore is built on first use (about a third of a second for a 1024-wide world); each realm's details on demand, in a few milliseconds.

- **Calendar and great events** (`lore/world.ts`): the present year (between 880 and 1440 of a named era, "after the Flood", "of the Reckoning"), one to three plagues that swept the Old World ("the Grey Death"), a great comet, and, when there are colonies, the Age of Sail. Each realm was founded in a seeded year by tier and government (empires after the kingdom at their heart; colonies after the Age of Sail), and each vassal joined its liege in a year and by a manner (conquest, marriage, inheritance, oath of fealty, submission).
- **Rulers and houses** (`lore/names.ts`, `lore/realm.ts`): hereditary realms have one to five ruling houses over their history, changed by usurpation, conquest, rebellion, marriage, election or the old line dying out; vassal counties and baronies are often held by cadet branches of their liege's house. Each reign has a ruler with a given name in the culture's manner (family name first in Sinic, Japonic and Koreanic lands; patronymics among Norse, desert and Celtic peoples; "son of" among dwarves), traits, often an epithet, a regnal number when a name repeats, how they came to the throne and how the reign ended (old age, battle, murder, plague, deposition). Republics, city-states and theocracies elect their leaders from leading families (priests take holy names); colonies have appointed governors; leagues a council. The current ruler shows age, traits, spouse (from an allied house when a marriage seals an alliance), heir or heir presumptive, a regent for a child ruler, the culture's law of succession, and a court of named officers by culture (Chancellor, Grand Vizier, Logothete, Master of Whispers, Forgepriest). A unit held in person by its liege shows the liege's ruler.
- **Diplomacy** (`lore/world.ts`): neighbours are realms that share a border (or coastal realms within ~900 km by sea). Past wars between neighbours are seeded through history, each with a name ("the War of Xulmopan", "the Hundred Years' War", "the Holy War"), a cause, a peace or treaty and an outcome consistent with today's map: a county won is held by its winner now, and its loser claims it still for two centuries. Relations come from shared faith and sect, shared culture, recent wars and claims: alliances (often sealed by marriage), friends, rivals, truces after recent wars and a few wars today (about one realm in thirty), with allies called to arms; rivals of one realm tend to ally against it. Houses that lost a throne by usurpation, conquest or rebellion may leave a pretender, sheltered at a rival court. Vassals show their realm's foreign affairs.
- **Vassals:** a tree of the realm's vassals, largest first, each with its ruler, people, how and when it joined, and unrest (a vassal of another people, or one claimed by a foreign power); rows open to their own vassals. Leagues list their members.
- **People:** people, town-dwellers, density, the mix of peoples (from the land's cultures, weighted by habitability), folk (humans, elves and dwarves, with a few halflings, gnomes, half-elves, half-orcs and others by culture), faiths (with dissenting sects), the largest cities and towns and estimated villages.
- **Trade and arms** (`lore/economy.ts`): the land is summed from per-barony statistics the world worker records (`RealmStats` in `gen/politics.ts`: area by biome, habitable area by culture, coastline, uplands, mean temperature and rain, and which baronies border which). Goods follow from them (grain, rice or maize, cattle, fish, salt, timber, wool, horses, furs, iron and stone, wine and olive oil in their climates, spices, sugar, cotton, dates, incense, ivory, tea, silk, pearls, amber, whale oil, honey, dyes and cacao, and by luck silver, gold, copper, tin and gems in the mountains), scaled by how much of the land its people work. Exports are goods the realm makes far more of than its share of the world's people; imports are staples it lacks and, for rich realms, luxuries. Trading partners are realms whose exports meet its imports, nearer (and by sea, much nearer) counting for more. Each realm is known for a named craft of its culture ("Jidid rosewater", "Kumkent composite bows"). Wealth ranks it among all independent realms, with a revenue in its coin (crowns, florins, dinars, taels, ryo, cacao beans). Armies: levies, standing troops, mounted share, ships of war (more for sea powers), walled towns, the culture's way of war and, for many realms, a knightly order named for the charge in its arms.
- **Faith** (`lore/faiths.ts`): each culture keeps a faith of its own kind: a monotheist church (Anglo, Latin, and by chance converted Slavs, Celts, Norse and Southrons), the faith of the desert prophets (and, by chance, the steppe), a pantheon (Southern), the old gods (Norse, Slavic), druidry (Celtic), the stars (Elvish), the forge and the ancestors (Dwarven), the eternal sky (Steppe), the way of heaven (Sinic, Koreanic, sometimes Japonic), the kami (Japonic), the Great Spirit (Woodland), the sun (Highland) and the feathered serpent (Jungle). Shared faiths split into sects by people (the mother church, a reformed church, an eastern rite), and a realm keeps its people's sect. Each faith has named gods or holy figures with their domains, teachings, clergy, temples, scripture, symbol, a head seated at a theocracy's capital or its people's greatest city, and holy places on the map.
- **Chronicle:** a dated timeline of the realm's founding, notable successions (new houses, child rulers, murders, deaths in battle and of plague), wars and peaces, marriages and alliances, vassals gained, conversions and sects taken up, the world's great events, and a few local ones (a cathedral consecrated, walls raised, a great fire, famine, flood, a dragon slain, the dead walking in the marches).
- **On the map** (`setRelations` in `world/political.ts`): while a realm is open, `relations://` raster tiles tint its own lands gold (the rest of its realm, for a vassal, pale gold), allies and league fellows blue, friends pale blue, realms at truce grey, rivals orange and enemies at war red with hatching, with deeper colour along their edges, fading out by zoom 13; dashed lines run from its capital to its trading partners'.


## Search (`src/search/`, `components/SearchBar.vue`)

A search box at the top of the map (a search button on mobile) finds places by name or by kind. Press **/** or **Ctrl/Cmd+K** to jump to it, the arrow keys to move through the results and **Enter** to go; **Esc** clears it. Choosing a result flies there and rings the spot for a few seconds.

- **What it covers:** cities and towns (with population and layout), realms, continents, islands, seas, oceans, gulfs, bays, straits, lakes, rivers, mountain ranges, peaks, hills, forests, deserts, marshes, plains and named roads, all as soon as the world is generated. Sewers and catacombs are listed at their town from the start (and at their entrance once the town's plan has been drawn). Villages (and keeps, monasteries and camps), caves, glades, towers, crypts, ruins and mines are indexed by the towns worker in the background, whenever the view needs nothing else, nearest first, block by block (without their tracks, and without keeping them); a note shows its progress, which takes several minutes for a whole world. Quarters, districts and notable buildings (inns, taverns, smithies, temples and the rest) become searchable once their town or village plan has been drawn.
- **Matching:** exact names first, then names and words starting with the query, then names containing it; typing a kind ("cave", "crypt", "sewers", "inn", "lake", "keep") lists that kind nearest first. Ties go to the more important and then the nearer place. Filter chips narrow the results to settlements, water, regions, caves and dungeons, roads, or places in towns. Each result shows its kind, details (population, tags, "in Anterina"), and its distance and direction from the map centre.

## Caves and groves (`src/lairs/`)

Caves and glades are placed with the villages, per 1° block on a jittered ~30 km grid (`towns/manager.ts`), and drawn as map icons from zoom 8.6 with their names from zoom 10.4. They follow the **Settlements & roads** toggle.

- **Placement:** caves in hill and mountain country (more likely the higher the ground), in the face of the steepest slope within 1.5 km; glades in the forests (and now and then in riverside woods, scrub and savanna), on the most level ground within 900 m. Both keep clear of towns and villages.
- **Tags** come from the site: a size (small, medium or large); for caves, sealed (no way out), wet or flooded where it rains, dry in deserts; for glades, one or two features (a great tree, a pond, standing stones, a stream (likelier by a river), a camp, ruins, rocks, flowers), and dry in arid or hot country (no water, yellowed grass and crowns).
- **Names** (`names/names.ts`, `lairName`) use the local culture's proper names (now and then an English compound, as in Watabou's "Starbog") with a noun that fits the size, water or feature (Hole, Grotto, Caverns, Catacombs, Halls; Glade, Dell, Glen, Stones, Pool, Oak), plus a few culture-specific nouns (dwarven Delve and Deeps, Elvish Bower, Celtic Nemeton). Descriptive forms appear too: "the Dripping Grotto", "the Troll's Den", "Glade of Whispers".
- **Caves** (`lair.ts`), after [Watabou's Cave Generator](https://watabou.github.io/cave-generator/): chambers of two or three overlapping round halls joined by a spanning tree of winding passages (plus the odd loop), stamped into a field, roughened with noise and traced as smooth walls by marching squares; specks and small pockets are cleaned up. Unless sealed, one or two passages run off the map edge as entrances. Pools fill low noise hollows in wet and flooded caves; boulders sit near the walls, stalagmites stand in clusters.
- **Cave levels:** small caves have one or two levels, medium up to three, large two to four (a tag such as "3 levels"). Each level has its own chambers and passages on the same footprint; only the top level has entrances, and deeper levels grow wetter. The ways down (carved stairs, a shaft with a rope ladder, or a steep scree slope) sit in chambers far from the entrance, clear of pools and boulders, and open into a chamber at the same spot on the level below, where the way up is marked in the same style; large caves sometimes have two ways down. Openings are drawn dark, the foot of a way up light, each with a caption ("Down to level 2").
- **Cave key:** chambers are numbered through every level from the way in, each with a heading and description chosen from what it holds: the cave mouth, the way down and the foot of the way up, pool chambers, great caverns (the largest fifth), stalagmite halls, grottoes (the smallest third) and plain chambers. Caves have an adventure hook, and their chambers carry creatures, hazards and treasure as in the dungeons.
- **Groves** (glades on the map): two to five noise-warped clearings (by size) in a forest of tree crowns packed on a jittered grid, joined by winding trodden paths (a spanning tree, a loop in larger groves, and a path in from the map edge, marked with an arrow). Each clearing has its own feature: the site's tags first, then a pick from the rest: a great tree, a hollow tree, standing stones (sometimes round an altar stone), a pond, a spring ringed with stones, a shrine heaped with offerings, a druid's hut, a camp, ruined walls (sometimes with a well), boulders or a flowering meadow. A stream may cross the grove, with a ford where it meets a path. Grass tufts fill the open ground; crowns keep off the paths.
- **Grove key:** clearings are numbered from the way in; the view lists an adventure hook and a heading and description for each (the ford too), with creatures, hazards and treasure as in the dungeons. A **hollow tree** opens on a second level, the hollow among its roots, reached by a rope down the split trunk: a round chamber with two or three root tunnels to smaller hollows (a hoard, a nest, a seep), numbered on from the grove.
- **Drawing** (`render.ts`): caves in ink on parchment, with a rock band and Watabou-style hatching (groups of short parallel strokes) round the walls, a 5 ft grid on the floor, pools, boulders and entrance arrows; glades with scalloped crowns sharing one inked outline, shadows and highlights, a 5 ft grid over the clearing, standing stones, tents and campfire, broken walls and water.
- **Views** (`view.ts`, `components/LairView.vue`): hovering an icon or name shows a card with the name, tags and a miniature; from about zoom 17, once the map is more than ~170 px wide on screen, hovering lays the map over the ground at its true size instead (with a faded rim). Double-click (or tap twice) to open the full view, with a tab per level (the arrow keys, or clicking a way up or down, also change level), Grid and Labels toggles, a north arrow, a scale bar and **Download PNG**; caves and groves show their key beside the map (below it on phones), and their PNG includes the title, hook and key. **Leave** or Esc returns to the map.

## Dungeons (`src/dungeons/`)

Dungeons in the manner of [Watabou's One Page Dungeon](https://watabou.github.io/one-page-dungeon/): a grid of 5 ft squares (`core.ts`) carved into rooms and corridors, with doors (open arches, doors, locked doors, secret doors, portcullises, bars), furniture, numbered rooms and a written key, on one or more levels joined by stairs, ladders, shafts or a spiral stair. Each way down opens at the same spot on the level below, in a room far from the way in.

- **Kinds** (`kinds.ts`):
  - **Mines** (1 to 4 levels): a main drift from the adit with rails and timber supports, wandering cross-cuts ending in stopes (worked chambers with ore, flooded workings, a miners' camp, a collapse), and a shaft between levels.
  - **Towers** (2 to 5 floors, a cellar half the time, and the roof): round floors of the same plan, with a spiral stair in the same place on every floor, one or two partitions with doors, rooms furnished by use (guard room, store, hall, library, study, bedchamber, laboratory, armoury, chapel; cells and a cistern below), arrow slits, a door in the ground floor wall and a crenellated roof with a beacon.
  - **Crypts** (1 to 3 levels): rooms mirrored about a central axis, a pillared hall on the axis with a statue or altar, burial vaults lined with sarcophagi, ossuaries stacked with skulls, chapels, a treasury and a guard room, and burial niches along the passages.
  - **Ruins** (1 to 3 levels): a roofless building of a hall and wings, cut into rooms whose walls have broken away in runs (rubble where they fell), collapsed floors, trees and bushes around and within; larger ruins have cellars below.
  - **Catacombs** (1 to 3 levels): a maze of narrow galleries (a randomised depth-first maze on a 4-square lattice, with extra openings), lined with niches (some still holding skulls), opening into ossuaries, burial chapels, vaults and shrines.
  - **Sewers** (1 or 2 levels): built from the town plan around the grate. The main tunnels follow the streets near it in straight runs (a water channel with a walkway either side), drains branch off under the lanes, junction chambers mark where tunnels cross, and side rooms (cisterns, stores, dens, a shrine, a collapse) open off the walkways; where a river or the sea lies within 150 m, a trunk runs out to a barred outfall. Larger city sewers have a cistern level below.
- **Key** (`key.ts`, with `keys/flavour.ts`): an adventure hook for the site, often with a reward or a complication, and, for each numbered room, a heading and a description drawn from what the generator placed there (no description repeats within a site while others are left; burial vaults sometimes carry an epitaph), the way down where there is one, and now and then a detail for the senses. Rooms may also note a **creature**, a **trap** or a **treasure**, chosen for the kind of site: entrances are quieter, guard rooms and dens likelier to be occupied, treasuries always hold something, and deeper levels are more dangerous and richer. No note repeats within a site.
- **Drawing** (`render.ts`): hatched rock (or open ground, for ruins and roofs), pale floors with a drop shadow on a 5 ft grid, thick ink walls, doors set in the walls, water with ripples, rubble, rails and furniture (sarcophagi, pillars, niches, altars, statues, chests, barrels, crates, bones and skulls, beds, tables, bookcases, braziers, a throne, a well, carts and ore), ways up and down captioned with the level they lead to, entrance arrows and room numbers placed clear of stairs and furniture.
- **Placement** (`towns/manager.ts`): towers, crypts and ruins on a jittered ~45 km grid per 1° block, kept clear of towns, villages, caves and groves (towers on rises, more often in hill country; crypts and ruins on gentle ground), with a size and a number of levels or floors; a **mine** under every mining camp, entered at the mouth of the camp's first adit and marked there on the camp's plan (searchable at the camp until the plan is drawn), named after the camp. **Sewers** lie under every city and every town of 4,000 or more, with a grate drawn on the plan on a main street near the centre; **catacombs** under every city and about half the towns, with a stair in the graveyard, by the temple, or in the market (`townUnderground` in `core.ts`). Names (`dungeonName` in `names/names.ts`) use the local culture: "Ashcombe Tower", "the Sunken Crypt", "the Witch's Spire", "the Sewers of Makaba".
- **Views** (`view.ts`, `components/DungeonView.vue`): standalone sites show icons from zoom 8.6 (a tower, a tomb, broken walls, crossed picks) and names from zoom 10.4; grates, catacomb stairs and mine adits show on town and camp plans from zoom 13.6, with names from zoom 15.2. Hovering shows a card with a miniature of the way in; double-click (or tap twice) opens the dungeon: a tab per level (opening on the way in, so a tower opens on its ground floor), Grid and Numbers toggles, the map, and the hook and key beside it (below it on phones). Clicking a stair goes to its level; the arrow keys change level too. **Download PNG** saves the level shown as a page with the title, hook, map and key; **Leave** or Esc returns to the map.

## Climate tuning against Earth

`tuning/climate/` scores the climate model on real Earth. It runs the generator's climate pipeline on WorldClim 2.1 elevation (the `heightmap` option of `generateWorld` skips tectonics and erosion) and compares the result with observed WorldClim monthly climatology (1970–2000).

```sh
npm run earth:fetch                      # once: downloads ~46 MB to tuning/data/ (git-ignored)
npm run earth:eval                       # score current parameters against tuning/climate/baseline.json
npm run earth:eval -- --update-baseline  # accept a new score
npm run earth:eval -- --res=512          # faster, coarser
```

- **Reference map:** the observed monthly data is reduced to the same inputs the simulation produces (mean, warmest and coldest month temperature, summer/winter precipitation) and classified with the same Köppen code. Differences therefore measure the simulation, not the classifier.
- **Reported metrics** (area-weighted over land):
  - exact Köppen class accuracy
  - main-group (A–E) accuracy and Cohen's kappa
  - annual, warmest-month and coldest-month temperature RMSE
  - precipitation log error and bias
  - summer-rain-share error
  - group shares and a confusion matrix
- **Objective:** these combine into one `OBJECTIVE` (0–1, higher is better). The command exits non-zero if it regresses against the baseline.
- **Maps:** written to `out/earth/koppen-{observed,simulated,agreement}.png`. In the agreement map, green is the same class, yellow the same group, and red a different group.

After any change to climate code or `CLIMATE`/`KOPPEN` constants, run `npm run earth:eval` and make sure the objective did not regress. Data: Fick & Hijmans (2017), WorldClim 2.1, CC BY 4.0.

## Roadmap

Phase 1 (done): world generation and a zoomable globe.

Phase 2: zoom into sites. [Watabou's generators](https://watabou.github.io/) set the visual bar for each scale:

| Scale | Reference | Plan |
|---|---|---|
| Region / realm | [Realm](https://watabou.github.io/realm.html) | **Done:** settlements, roads, villages, realms (counties to empires) with borders, labels and arms. |
| City | [City](https://watabou.github.io/city.html) | **Done:** walls, wards, streets, buildings, rivers and coasts, slope-aware layout, harbours and docks. |
| Village | [Village](https://watabou.github.io/village.html) | **Done:** farming and fishing villages, logging and mining camps, monasteries, keeps. |
| Building interiors | [Dwelling](https://watabou.github.io/dwelling.html) | **Done:** floor plans for every building (hover preview, double-click to go inside), with an isometric exterior. |
| Caves | [Cave](https://watabou.github.io/cave.html) | **Done:** Cave systems seeded from mountain and karst sites. |
| Groves | [Glade](https://watabou.github.io/glade.html) | **Done:** multi-clearing groves with paths, shrines, huts, standing stones, a hollow tree with a level below, and a key. |
| Dungeons | [One Page Dungeon](https://watabou.github.io/one-page-dungeon/) | **Done:** mines, towers, crypts, ruins, catacombs and city sewers, with levels, numbered rooms and a key. |

Each site gets a seed derived from the world seed and its location, so every zoom level is deterministic and shareable.
