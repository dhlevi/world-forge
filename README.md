# World Forge

Demo: https://dhlevi.github.io/world-forge/

A browser-based procedural fantasy world generator. You start with a whole planet on a zoomable globe (or flat map) and can zoom in through roads and villages to the streets and buildings of individual towns. Everything runs client-side, with no server.

Stack: TypeScript, Vue 3, Vite, MapLibre GL JS. Node.js runs the tooling and the headless preview script.

## Quick start

```sh
npm install
npm run dev        # http://localhost:5173
npm run build      # type-check + production build to dist/
npm run preview -- --seed=forge --layers=fantasy,terrain --at=-57,-33,7   # headless PNGs in out/ (tiles use the first layer)
```

### GitHub Pages

`.github/workflows/deploy-pages.yml` builds the site and publishes it to GitHub Pages on every push to `main` (or by hand: **Actions › Deploy to GitHub Pages › Run workflow**). Once, in the repository's **Settings › Pages**, set **Source** to **GitHub Actions**. The site is then at `https://<owner>.github.io/<repository>/` (for this repository, https://dhlevi.github.io/world-forge/).

Pages serves a project site from `/<repository>/`, so the workflow builds with `BASE_PATH=/<repository>/`, which `vite.config.ts` uses as Vite's `base`. Local builds default to `/`; to test a Pages build locally, run `BASE_PATH=/world-forge/ npm run build && BASE_PATH=/world-forge/ npm run serve` and open http://localhost:4173/world-forge/.

The world regenerates when **Generate** (or **Random**) is pressed. The settings of the world shown are kept in the page address (`?seed=forge&land=0.3&plates=14&erosion=0.5&settled=0.6&drift=0.3&races=1&res=1024`, `src/url-params.ts`), so a link or bookmark opens the same world; any setting left out takes its default, and values out of range are brought within it. Each new world is a step in the browser history, so Back and Forward return to the worlds made before. Settings changed but not yet generated are not written to the address. Hovering (or tapping on mobile) shows elevation, Köppen climate, temperature (mean, warmest and coldest month), precipitation (and how much falls in summer), prevailing wind, ocean current (at sea), biome and plate for that point. Hovering a cave or glade icon shows a preview card (or, close in, its map laid over the ground); double-click it to open its map (see **Caves and groves**). Towers, crypts, ruins and mines, and the sewer grates and catacomb stairs drawn on town plans, work the same way (see **Dungeons**). Clicking a realm's name or arms opens its details (see **Realm details**). From zoom 17, hovering a building in a town or village draws its ground-floor plan over it; double-click it (on touch screens, tap it a second time) to go inside (see **Building interiors**). The globe button switches between globe and flat Mercator views. The URL hash (`#zoom/lat/lon`) saves the current view.

## Generation pipeline (`src/gen/`)

The world is simulated on an equirectangular lon/lat grid that wraps east–west. All tunables are in physical units (km, m, °C, mm/yr) in `src/gen/config.ts`, so results look the same at every **Detail** setting.

1. **Tectonics** (`tectonics.ts`): plates are weighted, noise-warped Voronoi regions on the sphere, each rotating about a random Euler pole. A continental-crust field (plate bias + blurred noise) separates continents from ocean floor. Relative plate motion at boundaries produces:
   - convergent continent–continent collisions: wide, high ranges
   - ocean–continent subduction: coastal ranges set back from a trench
   - ocean–ocean subduction: the denser plate dives under the other, leaving a trench on one side and a single island arc, broken into separate island groups, behind it on the overriding plate
   - divergent boundaries: mid-ocean ridges and continental rifts

   Boundary ranges have a main ridge with foothills, and low-frequency noise breaks them into segments of varying height, so a range doesn't run the full length of a plate boundary. Interior ranges (Appalachian/Ural style) follow the boundaries of an older, finer plate pattern; only some of those ancient sutures survive as ranges. Sea level is then set by area-weighted quantile so the land fraction is exact, and enclosed seas larger than 25,000 km² become lowland basins.
2. **Initial climate** (`climate.ts`):
   - **Temperature** comes from latitude and the lapse rate.
   - **Wind:** a per-cell field built from the three circulation cells (easterly trades converging on the equator, poleward westerlies, polar easterlies). Low-frequency noise makes the flow meander, it turns away from steep terrain, and land friction slows it.
   - **Moisture** is carried along the wind with semi-Lagrangian advection, using fixed steps in km. Air picks up moisture over the sea and rains out over land. Lifted air condenses as it cools, which gives windward mountains heavy rain and leaves rain shadows downwind. Land returns part of its rain to the air (evapotranspiration).
   - **Rain bands** come from wind convergence: where the winds meet (ITCZ, polar front, onshore flow slowing over land), air rises and rain increases. Where they spread apart (subtropical and polar highs), air sinks and dries. The bands follow the simulated winds, so they bend around continents rather than lying flat at fixed latitudes.
3. **Erosion** (`hydrology.ts`): priority-flood depression filling and steepest-descent routing, then an implicit stream-power solver (Braun & Willett 2013) weighted by precipitation. Closed basins partly fill with sediment.
4. **Final climate**: recomputed on the eroded terrain, now including **ocean currents** (`ocean.ts`):
   - **Wind-driven gyres:** surface water drifts with the wind and turns into boundary currents where it meets a coast. Subtropical gyres run poleward along western ocean boundaries (warm) and equatorward along eastern boundaries (cold, with upwelling). Subpolar gyres reverse both, which warms high-latitude west coasts. Narrow seas form only weak currents.
   - **Sea temperature:** carried along the currents and relaxed back toward the latitude baseline.
   - **On land:** the wind carries the sea-temperature anomaly inland. Air over cold water is stable and rains less, which produces foggy coastal deserts.

   **Seasons:** the climate is simulated for northern summer and northern winter.
   - **Temperature swing:** the warmest and coldest month differ from the mean by an amount that grows with latitude and with continentality (how far the wind has travelled from the sea), so coasts are mild and interiors are extreme.
   - **Seasonal rain:** the wind bands and rain belt shift toward the summer hemisphere, and a monsoon term turns winds onshore in summer and offshore in winter. Moisture transport runs once per season to give summer and winter precipitation; annual precipitation is their mean.
   - **Köppen–Geiger** (`koppen.ts`): the full set of 30 classes (Af…EF), from mean, warmest- and coldest-month temperature and seasonal precipitation, using the standard map colours. On test seeds the land shares come out close to Earth's: about 19% tropical, 27% arid, 18% temperate, 24% continental and 12% polar.
5. **Rivers & lakes** (`rivers.ts`, `river-index.ts`): flow is accumulated, weighted by precipitation. River polylines are split by discharge class, jittered, and Chaikin-smoothed. Lakes form in deep basins only where precipitation is high enough to keep them filled.
   - A shared **river index** bins the segments for fast distance queries. Widths taper smoothly downstream (each feature spans one discharge doubling, so its width grows from one class to the next along its length).
   - **Meanders:** distances to a river are measured from a point displaced by a smooth noise field (domain warping, 9 km down to ~0.5 km wavelengths), so the straight coarse courses bend the same way in the tiles, the terrain sampler and the town plans.
   - **Valleys:** within a floodplain that widens with the river, the sub-grid detail relief fades out, the floor sinks a few metres toward the banks and the channel is cut below them, so rivers never climb over noise ridges.
6. **Biomes** (`biomes.ts`): a Whittaker-style classification from annual temperature and precipitation, refined by terrain and water:
   - **Ice:** ice caps where summers stay below freezing, or glaciers where cold summers meet heavy snowfall.
   - **Treeline:** trees need a warmest month of at least 10 °C, so cold, dry land stays tundra.
   - **Altitude zones:** alpine meadow above the treeline, montane forest on high wet slopes.
   - **Wetlands and marshes** on flat floodplains and lakeshores.
   - **Mangroves** on hot, wet, low coasts.
   - **River valleys / oases:** green corridors where large rivers cross dry country.
   - **Salt flats** in closed basins too dry to hold a lake.
7. **Streamlines** (`streamlines.ts`): evenly spaced streamlines with arrowheads, traced through the wind and current fields for the overlays.
8. **Old World and New World** (`oldworld.ts`): settlement spreads from a heartland (temperate, watered land of the largest landmass) by travel cost: over land, dearer through mountains, and across the sea at six times the cost, so a continent fills before the next is reached. The first share of the land to be reached (the **Settled world** slider) is the Old World. Other landmasses then go wholly one way or the other, by which side holds most of them; only the heartland's own landmass may be split, along a frontier that tends to follow its ranges. Because whole landmasses go together, the actual share can differ from the slider by several points. The rest is the **New World**: no cities, tribal towns and villages far apart, New World cultures, tribal realms, and a few colonies of Old World realms on its coasts. The **Old & New World** map layer shows how this came about: Old World land is shaded by when the spread reached it (dark near the heartland, pale at the last), with a thin line at each tenth of the spread, a dark line along the frontier and a ringed dot at the heartland; New World land is teal, and land that the whole-landmass rule moved to the other side is drawn in lighter tints. Its key (`components/OldWorldLegend.vue`) gives the setting, the share of land the spread reached, the share that is Old World and how much whole landmasses gained or lost, and the number of Old World cities and towns, New World towns and colonies; hovering shows whether a point is Old or New and at what share of the spread it was reached. Recording the spread (`SpreadTrace`) changes nothing in the world.
9. **Settlements & roads** (`settlements.ts`):
   - **Habitability:** each land cell is scored on mild temperatures (warmest month ≥ ~10 °C, not too hot), enough rain, low elevation, gentle slope and biome. Rivers, sea coasts and lakeshores add a bonus.
   - **Cities and towns** are founded greedily on the best sites. In the Old World cities are at least 280 km apart and any two towns or cities 65 km apart (about 11,000 towns and 600 cities on a 1024-wide world, settling 20 seconds or so). In the New World there are no cities, and towns are at least 190 km apart: these are **tribal towns** (about half the size, unwalled, built as large villages). Population grows with site quality; cities and larger towns are walled.
   - **Colonies** (`colonies.ts`): about one New World coastal town in eleven (three to fourteen in all, at least 400 km apart) becomes a colony, a fort or a trading post of the seafaring Old World culture whose coast lies nearest (no one culture founding more than half of them), so each power's colonies cluster on the shores facing it. Colonies take their founders' culture and are named after a home town ("New Ashford"), as forts ("Fort Valcia"), landings and posts, or as ports. They are built as Old World towns, and the villages round them are ordinary villages.
   - **Placement:** river towns sit on the river line, offset to one bank so the river runs through the town. Coastal sites are nudged onto land at full shoreline detail (`detail.ts`, which samples the same sub-grid terrain as the tiles). A grid cell beside the sea may lie well back from the true shore, so a coastal town (`nearestWater`) moves to the water's edge if the sea lies within 25 km (its centre about half its core radius inland, so its plan reaches the water and gets a harbour), and is otherwise not coastal at all; a coastal river town keeps its place and is coastal only if the sea lies within its core. A coastal or lakeside town whose core is more than half water at full detail (an islet or spit that only the fine shoreline shows) moves to the nearest spot within 3 km whose core is mostly land (`landfall`), searching on to 8 km if there is no dry ground nearer; a town left with almost no land (over 80% water) is dropped, about one in 10,000. Only coastal towns take harbour, bay or cliff names, fishing and salt in their names, or the name Port {N} as a colony.
   - **Universities** (`markUniversities` in `world.ts`): the richest Old World realms (by the people of their cities: the top 6 %, one to ten, of realms with at least 30,000 city dwellers) have a university in their largest city, and the richest third of those a second in another great city. The location title calls it a university city, search lists it, and the realm's chronicle tells of its founding.
   - **Roads** link neighbouring settlements (a relative-neighbourhood graph: major roads between cities, minor roads between towns). Each road is routed by A* over the grid, with costs for slope, biome (wetlands, rainforest and ice are slow) and bridges. Reusing an existing road is cheap, so routes merge into trunk roads. Roads are smoothed and stop at the edge of each town plan.
   - **Fine layout:** the grid route only fixes a vertex every ~39 km, so each stretch between two vertices is laid out again on a strip of lanes either side of the straight line (3 km steps and up to 8 km off the line for major roads, 5 km steps and 7.5 km for minor ones). A dynamic programme picks the cheapest path over the sub-grid terrain the tiles draw: it bends round hills and spurs, keeps to valley floors, runs beside rivers (cheaper near a bank, a toll to cross that grows with the river) and wanders a little across open ground (a smooth noise field). The road moves at most one lane per step, so it stays smooth. Stretches are cached by their end points, so roads sharing part of a route share the same line. After smoothing, a slight hand-drawn waver is added and the line is simplified (Douglas–Peucker, 60 m).
   - **Keeping roads on land:** the grid route only knows 39 km cells, so at full detail it can cut across bays, lagoons and lakes. Near water (low land, coasts and lakeshores) each road is resampled every 600 m, and every 150 m around wet samples; short wet stretches are pulled onto the nearest shore and eased, and any remaining open-water crossing longer than 750 m (counting islet-hopping across an archipelago as one crossing) breaks the road at the shore. Short crossings stay as bridges or causeways, and rivers are always bridged. Roads that meet a town in the water start at the shore instead.
10. **Names & labels** (`src/names/`, `features.ts`):
   - **Cultures** (`cultures.ts`, `culture-map.ts`, `world-cultures.ts`, `traits.ts`): culture hearths at least 1,200 km apart are chosen by climate suitability and spread by distance, with mountains and seas acting as borders and a heavy toll for crossing between the Old and New Worlds. **Each hearth is a culture of its own**, grown from one of twenty-three familiar **templates**: in the Old World Anglic, Nordic, Latinate, Celtic, Desert, Slavic, Southron, Steppe, Sinic, Japonic, Koreanic, Indic (after the Indian subcontinent), Sahelian (West Africa and the Sahel) and Zanji (the Swahili coast and the Ethiopian and Somali highlands); in the New World Jungle, Woodland and Highland; in either world Islander (Polynesia); and the fantasy races Elvish, Dwarvish, Halfling and Orcish (Old World) and Saurian lizardfolk (either world). Several cultures may share a template. Each template is a **bundle**, one file in `names/bundles/` (the fields are described in `names/bundle.ts`): its naming parts and the climate it likes, its language and given names, family and house names, epithets, ethos and traditions, customs, ruler titles and realm styles, leanings toward city-states, republics, empires and leagues, succession, court, army, crafts, coin and goods, heraldry and faith, and how its people spread. Every table keyed by template is built from the bundles, so a new culture needs only a new file and a line in `names/bundles/index.ts` (new templates go at the end, since a world's cultures refer to their template by its place in the list). Peoples keep to their homes as they spread (each bundle's `spread`): dwarves to the mountains (land below 700 m costs them eight times as much to cross), lizardfolk to hot wetlands, mangroves and jungle, halflings to the lowlands and hills, orcs away from deep forest, and islanders cross the sea almost freely but the land only slowly. With **Fantasy races** off, only human templates are chosen. A culture takes its own name from its language (a root of its tongue plus an ending: "the Ramite", their own name "Ram"), its own language (see **Languages**), and **traits** in the manner of Crusader Kings: an **ethos** (Bellicose, Stoic, Bureaucratic, Spiritual, Courtly, Communal, Egalitarian or Inventive, weighted by template), three or four **traditions** chosen from its lands and template (Seafarers, Horse Lords, Mountaineers, Forest Folk, Desert Wanderers, Jungle Dwellers, Winter-Hardened, River Folk, City Builders, Merchant Princes, Legalists, Warrior Culture, Clan Ties, Monastic Learning, Master Craftsmen, Storytellers, Sacred Hospitality, Stargazers, Deep Delvers, Pastoralists, Raiders, and **Cosmopolitan** or **Insular**, never both) and **customs** (who bears arms, marriage, building, dress, food, and two festivals named in the language). Traits change the world: their multipliers raise or lower the chances of city-states, republics, theocracies, empires, leagues and breakaway duchies, how readily a people founds colonies, and its levies, cavalry, fleets, revenue and crafts. Cosmopolitan peoples (often on coasts and rivers, or egalitarian, inventive or courtly) have many other folk living among them, from all over the world (several minorities of 2 to 11 % each), warmer relations with other peoples and a little more trade; insular peoples (in mountains, cold, desert or jungle, or bellicose, stoic or spiritual) have almost none, and cooler relations with other peoples. The culture map records each culture's hearth and the make-up of its lands (coast, uplands, forest, grassland, desert, cold, heat, rain, jungle, river land); every thread rebuilds the same cultures from that and the seed (`setWorldCultures`), so `CULTURES` holds the world's cultures everywhere. Each template still has its own terms for features (Fjord, Wald, Bahr…).
   - **Languages** (`src/lang/`): every culture has a generated language grown from its template (`templates.ts`): a weighted inventory of consonants and vowels in IPA (`phonemes.ts`), syllable shapes and allowed clusters, consonants allowed at word end, stress (or tones for Sinic, vowel harmony for Steppe), spelling of each sound and spelling rules (Latin c, Nahuatl qu and tl, Japanese shi and tsu, pinyin j, q, x), a grammar (word order, adjective position, articles as words, prefixes or suffixes, plurals, possession by suffix, prefix, particle, "of" or construct, two noun classes or none, tense by suffix, prefix or particle, subject agreement, prepositions or postpositions), name endings and seed words. **Drift** drops and adds sounds, reweights them, changes spellings, adds syllable shapes, re-rolls grammar features and picks sound changes (th → t, final -a → -e, doubled consonants simplified) that turn the template's old naming parts into the language's own. Words are generated per English gloss and are deterministic (`language.word("river")` is always the same); a core vocabulary of about 450 words (`lexicon.ts`) appears in the dictionary, and any other English word gets one on demand. **Names**: with little drift most names are the template's old forms after the language's sound changes; with more, they come from the language: a root with a place word ("-ford", "-heim" or the language's word for town, hill, river…), two words compounded, or a longer root. Given names, family names (family name first in Sinic, Japonic and Koreanic cultures), house names, deities and festivals come from the language too. **Language families and sound change** (`sound-change.ts`): peoples of one template are kin wherever they live, and peoples of related templates (the Anglic, Nordic and Dwarvish stock; Latinate and Southron; Celtic and Elvish) are kin where their homelands lie within about 3,600 km; each family descends from a **proto-language** grown from its largest people's template ("Proto-Varskic"; a tongue with no living kin has its own older form, "Old Varskish"). Each daughter went through two to six **sound changes**, in order, picked from about thirty regular shifts (stops softened between vowels, final devoicing, lost final vowels, palatalization before front vowels, umlaut, vowel raising, rhotacism, h-loss, cluster simplification…), only those that touch the parent's words. A daughter inherits most of the parent's words through its changes (fewer with more drift, and fewer again for kin of another template), remaps lost sounds to the nearest it has, mends clusters and endings it does not allow, and makes new words for the rest; so sister tongues share cognates that match sound for sound. `translate.ts` turns simple English into the language: noun phrases with articles, adjectives, plurals and possession ("the king's sword", "city of the river"), numbers (`numbers.ts`: typed as digits or words, "3" and "three" alike, standing before or after the noun as the language has it), possessive pronouns for all six persons ("my", "thy", "his", "her", "its", "our", "your all", "their": a word of its own before or after the noun, a suffix or prefix on the noun, or the plain pronoun with the language's possession marker, by template and drift), pronouns, one verb with tense, negation and agreement, and phrases with prepositions, in the language's word order, with a word-by-word gloss.
   - **Counting** (`lang/numbers.ts`): every language counts in a base: tens for most, twenties (scores, with tens below twenty) for Celtic, Jungle and Highland peoples, twelves (dozens) for dwarves, sixties (with tens below sixty) for lizardfolk, and tens with fives counted on the hand ("six" is "hand and one") for orcs; drift can give a people another. The number words are built from roots (the units, the ten or the hand, each power of the base, and "and"), each kept distinct from the others, with the larger part or the units first ("twenty-three" or "three-and-twenty"), the multiplier before or after its power, tens and units in one word or two, "and" between the parts, before the last or not at all, and nouns plural or singular after a number. `translate()` reads numbers typed as digits ("1240", "1,240") or English words ("three hundred and five", "a dozen" is left to its article), so "1" and "one" translate the same. The Grammar tab shows how the language counts, with a table of numbers in words and in its numerals and how each is built ("2×20 + 3"); the dictionary shows the number words as the language counts them.
   - **Writing systems** (`lang/script.ts`): every language has a script, drawn as SVG from the language's own sounds and seed. Scripts are of two structures: **alphabets**, one letter per sound (Latin-like letters, each a body on the x-height with a mark of its own, every sound with its own combination, angular runes, ogham notches on a stem line, Tengwar-like elvish letters built from their sounds' features (the bow shows where a sound is made: open for the teeth, closed for the lips, hanging for the back of the mouth, hanging and closed for the throat; the stem shows how: lowered for stops, raised for fricatives, short for nasals and glides; a doubled bow voices it; r, l, s and h have letters of their own), written with the vowels as marks above the consonants or, in full mode, as letters, a right-to-left abjad that leaves short vowels unwritten (its letters made as Arabic letters are, from fourteen skeletons on the joining line told apart by dots above or below, every sound with its own combination), a Devanagari-like abugida with a head stroke, an inherent vowel, vowel signs and a mark for a silent consonant, and a square Phags-pa-like script written in columns from the top down and left to right, each letter a head (a top bar, with ticks or doubled), a body hanging from it (a squared meander, comb, box, hooked stem, two legs or spiral) and a foot, every sound with its own combination, each syllable a stack of letters joined by their stems, with a after a consonant unwritten; its digits are letters of the same kind and its zero a hollow square), and **syllabaries**, one sign per syllable (brush-stroke kana, hanzi-like signs built of radicals, Hangul-like blocks composed from consonant and vowel letters whose shapes follow the sounds' place and manner, glyphs in cartouches on stone, and cuneiform wedges pressed in clay). The style follows the template (elvish letters for elves and halflings, and now and then for a human people of Anglic, Germanic, Latinate, Southron, Slavic, Celtic or Nordic stock; the square script or runes for Steppe peoples; runes for Nordic, Dwarvish and Orcish peoples; ogham for Celtic; an abjad for Desert, Zanji and Sahelian; kana for Japonic, Islander and Woodland; Hangul-like blocks for Koreanic; glyphs for Jungle and Highland; cuneiform for Lizardfolk), and drift can give a people another. Writing runs left to right, right to left or top to bottom by style. **Numerals** follow the script: positional digits with a sign for zero (Latin-like, elvish, abjad, where zero is a dot, and Devanagari-like scripts), additive signs for one, five (or ten) and each power, repeated as Roman numerals are (runes and ogham, and some Latin-like scripts), a digit before each power's sign as Chinese numerals are (hanzi, kana and Hangul-like scripts), or digits built of dots and bars with a shell for zero (glyphs, and any script counting in twenties or sixties) or of corner and upright wedges (cuneiform). Positional alphabets write their digits with pen-made figures: Eastern-Arabic-like ones for the abjad (zero a dot), and, for the Latin-like, elvish and Devanagari-like scripts, invented figures that look nothing like our own: either quadrant figures (after the medieval monks' ciphers: an upright stem with marks off its top for one, two, three, four and six, and their sums for five, seven, eight and nine) or zigzag figures (after a counting in fives and ones: a bar across the top for each five, and one to four strokes zigzagging down beneath, so a figure can count to nineteen), drawn curved in the elvish script; a place worth more than the figures can hold is two figures under a bar. Numbers in a translation are written in the numerals, and read from left to right even in a script written from right to left. A **sigil** is made from a name: its letters are points on three rings (placed by the script), joined in order, bowed and mirrored, inside a double ring with the name written small in the script. Inspired by Watabou's rune and sigil generators.
   - **Meaningful names** (`names.ts`, `lang/translate.ts`): most names are made in English first and then translated, so every name means something. **Settlements** take a place word fitting the site (Harbour, Bay or Cliff on the coast; Ford, Bridge or Mill on a river; Hill on high ground; Wood in forest; Field or Meadow on grassland; Marsh; Fort for walled towns; City for cities; Town, Farm, Stead, Vale, Spring, Well or Stone anywhere) and a modifier (a colour or quality, a tree, beast or thing, or a founder's name): "Black Ford", "Oak Hill", "Salt Harbour". Languages that compound make one word of it, worn down to a syllable or two each ("Svartvad", "Belgrad"; head first in Celtic-like tongues); the others make a phrase in their own grammar ("Villa Nigra", "Bir Mizaj"). About one in eight keeps a name whose meaning is lost, and about one in eight an **old name**: a modifier and place word said in the family's proto-language, run together and worn down by the people's sound changes ("Kurmidna", Oak City, from Proto-Makbic \*kurawath-medina). Some old names are borrowed from the proto-language of the nearest people of another family (the **substrate**: the tongue of those who lived there first). Rivers (two in five) and islands (one in four) often bear old names too. The English gives the meaning, and the location title, search and river labels say where the name came from (`old` on labels and rivers, `nameOld` on settlements). **Features** take an English name from patterns for their kind ("Lake {N}", "the {A} Hills", "the Forest of {M}", "the Sea of {N}"), with adjectives suited to the kind (silver and still lakes, jagged and cloudy mountains, whispering forests) and the old poetic ones, and are translated phrase by phrase: articles, plurals, adjectives before or after, possession and proper names placed as the language places them. Colonies ("Fort {N}", "New {N}"), roads ("the {N} Road"), villages' dress ("{N} Keep", "{N} Abbey"), caves and glades ("the Dripping Grotto", "the Troll's Den"), towers, crypts, ruins, mines, sewers and catacombs are translated the same way. Each label keeps both: `name` (the local form) and `en` (the English, where it differs); settlements keep `nameEn`. Search matches either, and shows the other beside it; the location title shows the other form beside the name. `translate()` marks proper names (‹Varsk›) so they pass through unchanged, sets a proper name beside its noun ("Lake Varsk", "Varsk Hills", by the language's habit), and can treat capitalized unknown words as proper names (the translate box, realm names).
   - **Name bank** (`names.ts`): deterministic per world seed and key, with duplicate avoidance for world features. Each culture has large syllable and compound sets (several thousand to over 15,000 possible names each) and mixes its forms (syllables, compounds, a root with a plain ending, a syllable with a compound suffix, glued and two-word prefixes such as Aber-, "Stara " or "Castra ", the two-word ones for settlements only); seams that read badly (four consonants in a row, a chunk said twice) are drawn again.
   - **Villages, caves and glades** are named one by one as their 1° block is generated, so they cannot be checked against the whole world; instead no two in the same block share a name (a repeat draws again), and the large sets keep repeats between neighbouring blocks rare (in a 13° × 13° test area, about 1 nearby repeat per 100 places, down from about 1 in 6).
   - **Water bodies:** oceans (far from land), seas, inland seas and lakes (enclosed water by area), and gulfs, bays and bights found by casting rays from the coast to measure how enclosed the water is. Straits and channels are narrow passages with open water on both ends; they get a line label along the passage.
   - **Land:** continents, islands and isle groups; mountain ranges (with their highest peak and height), hills, forests, deserts, marshes and plains from smoothed biome regions (each land cell also records which of these it lies in, for the location title). Realms come from the political map (see **Realms, arms and the location title**).
   - **Close-zoom water lettering:** a water body keeps its main label until it spans about one screen; from then on it is lettered from a lattice of anchors fixed in Web Mercator space (a few per screen, one lattice per whole zoom band), so a lake, bay or sea stays named while it is in view. On the open sea each name holds a territory (a Dijkstra weighted by the feature's reach, so a bay keeps its own water against the surrounding sea). Anchors deep in the water are kept; near the shore the label's footprint is tested against the coastline as the tiles draw it at that zoom. Narrow water falls back to the anchors along its middle. Lettering continues to zoom 8 for oceans, 10 for seas, 11 for gulfs and inland seas, 12 for bays, bights and straits, and 13 for lakes.
   - **Lines:** rivers are named per system (the main stem keeps one name to the sea), major roads ("the X Road", "the King's Road"). Elongated regions get curved line labels along their main axis.

11. **Special features** (`special.ts`): placed after the realms and names, each from its own random stream keyed by the seed, so they never change the names, borders or settlements made before them.
   - **Volcanoes:** tectonics records a volcanic field without touching its random draws: high along continental subduction arcs and island arcs, lower along rifts and mid-ocean ridges. Cones stand where that field is strongest (at least a third of its peak), plus two to five hotspots, at least 320 km apart and five to thirteen in all by land area; each moves to the highest ground within 60 km and is **active**, **dormant** or **extinct**. Its label gives its height and state ("Mount Varsk (3412 m, active)"). Volcanic soil rings each cone (70 to 120 km), and **lava fields** lie within 40 to 75 km of active vents.
   - **Ash lands:** up to four active vents throw ash downwind along the prevailing winds, a plume of grey waste that kills the land beneath; a plume of 12,000 km² or more is named ("the Ashen Waste", "the Varsk Cinderlands").
   - **Geysers and hot pools:** geyser fields and boiling, coloured pools lie near volcanoes that are not extinct, and mineral pools in dry country; each is a named point with its own icon.
   - **Glaciers:** ice above 1,500 m where the warmest month stays below 6 °C and enough snow falls (over 350 mm), with tongues running down the river valleys; the largest (2,500 km² or more, up to eighteen) are named.
   - **Mushroom forests** (with **Fantasy races** on only): one to three regions of giant fungi grown through warm, wet forest, preferring volcanic soil.
   - **Cursed lands** (with **Fantasy races** on only): two to six woods and mires (about a third of them mires), each begun at least 45 km from any town (70 km from a city) and grown to 15,000 to 50,000 km² through the woods or the wet lowland, round the towns' own outskirts. Each is named from grim adjectives of its own ("the Blighted Wood", "the Weeping Mire", "the Witchwood of {N}") and has at its heart an abandoned village (about half), a ruin or a crypt, with a story of how the curse came about (a witch burned by the villagers, a necromancer's spell gone wrong, an oath broken on the old gods' altar, a slain wyrm's blood, a fallen star, a pact to escape the plague, a cheated hag), what became of the place, what the curse does to the land now, and what is said of lifting it (`raster.curses`). The tiles paint cursed ground with a sickly mottled tint; the fantasy map draws dead trees in its woods and withered tufts in its mires. No new villages are founded inside; its caves and glades are tagged "cursed" (grey, dying groves with a key and hooks of their own), and its heart is opened from the map like any other site, its key beginning with the curse's story.
   - **Mages' towers:** about half the university cities have a college of magic ("the Tower of the Magi", "the Astronomers' Tower", "the Violet College"), and in fantasy worlds about one city in eight of 20,000 people or more has a mage's tower ("the Silver Tower"), named in the city's language (`s.tower`). The tower stands on the city's highest free ward in its walled garden, as in a city of mages, can be entered (the mage's tower interior), is listed by search before the plan is drawn, and the location title names it.
   - **Canyons:** stretches of larger rivers through high, dry country (above 350 m, under 800 mm of rain, cut at least 50 m below their rims or above 900 m) at least 120 km long, the longest on each river and up to twelve in all, drawn and lettered along their course.
   - **Cliffs:** sea cliffs where land of 350 m or more meets the sea, and escarpments where the ground drops 900 m or more, chained into lines of at least 150 km (up to sixteen), drawn as hatched ticks and lettered along their length.
   - **Drawing:** the fantasy and terrain tiles paint each kind with a texture of its own (ash speckle, glowing lava veins, glacier crevasses, fungal spots, canyon strata); the Biomes layer shows them in the colours of its key. The fantasy map draws volcano icons (a cone and crater, with lava and smoke when active, sized by height, and smaller when zoomed out: under half size on the globe, full size from zoom 7) at every zoom and giant mushrooms in place of trees; ash, lava and ice have no trees. Hovering names the ground ("Lava field (Hot desert)") and any active volcano within 150 km.
   - **The world reacts:** towns on ash or lava are ashen and smaller (about 0.6 of their people); towns within 70 km of geysers or pools are spa towns; towns near a live volcano or a canyon mine, and the location title says so. Villages shun glaciers and mostly shun ash and lava, and mine on volcanic ground and by canyons. Faiths take volcanoes, geysers, hot pools, glaciers, canyons and mushroom forests as holy places, each with words of its own ("the mountain whose fire gave birth to the world"), and their myths tell legends of them. Lairs near them change too (see **Caves and groves**).

## Rendering (`src/render/`, `src/worker/`, `src/world/`)

- The map is MapLibre GL with the globe projection. A custom `world://` protocol serves raster tiles that a pool of Web Workers renders on demand. One worker generates the world, then shares it with the rest.
- Tiles sample the grid with bicubic interpolation and add **fractal sub-grid detail**: more noise octaves as you zoom in, rough at coastlines and ridged in mountains. Coastlines and ranges keep showing structure down to ~10 m/pixel, and tiles stay consistent across zoom levels.
- Raster tiles go to zoom 17 (overzoomed beyond).
- Hillshading uses zoom-dependent vertical exaggeration. Terrain colour blends domain-warped biome colours with rock, snow (which needs both cold and enough precipitation) and sea ice.
- **Fantasy map** (`fantasy.ts`) gives a hand-drawn atlas look, inspired by Watabou's Perilous Shores:
  - Land is drawn as parchment tinted by biome, with soft sepia hillshading, snow and paper grain.
  - The sea is pale blue-grey, darkening with depth, and coastlines are inked.
  - Concentric ripple lines follow each coast. They come from a chamfer distance-to-shore computed over a 16 px tile margin, so they line up across tile edges.
  - Map symbols are placed on a jittered grid anchored in global pixel space and drawn back-to-front:
    - mountains (hatched, with snow caps where cold), hills
    - round deciduous trees or conifers, by forest biome
    - marsh tufts
  - Symbols are deterministic per seed and zoom. Mountains and hills are drawn up to zoom 11; trees and marsh tufts continue to the deepest tiles, growing a little and thinning out so forests still read as forests. Symbols keep off rivers and the fine shoreline.
  - **Rivers** are drawn into the tiles: a single ink-blue line while thin, then a pale channel between inked banks (with a ripple line inside broad rivers). They never get thinner than a zoom-dependent minimum, grow into their true width at close zoom, show only the largest rivers on the globe, stop at lakes, and open into the sea without an inked coast across the mouth.
  - **Contours** from zoom ~9: an interval that halves with each zoom (200 m at zoom 9 down to 2.5 m), every fifth line darker, fading out where lines crowd together. From zoom ~11.5 steep ground gets a rock stipple.
- **Lettering** (`components/label-style.ts`) uses IM Fell English (roman, italic and small caps, SIL OFL, bundled in `public/fonts/` and rendered locally through MapLibre `font-faces`, so no glyph server is needed). Labels appear by rank and zoom: realms and oceans on the globe, seas, ranges and forests regionally, lakes and smaller rivers closer in; water names are italic blue, regions are spaced capitals, settlements are small caps. Land, settlement and town lettering is drawn 20% larger than water names, on a firmer, more opaque halo, so it stays readable over forests and hatching.
- On the analytic layers rivers are a GeoJSON line layer whose width scales with discharge and zoom, growing into their true width (from ~12 m upstream to a few hundred metres on big rivers) at high zoom. The tile URL carries a river flag (`world://gen/layer/r|-/z/x/y`). Wind streamlines are a GeoJSON line layer drawn with a transparent-to-white gradient.

## Villages and town plans (`src/towns/`)

Everything below world scale is generated on demand in a dedicated web worker (`manager.ts`, `worker/towns.worker.ts`), so the map never stalls. It is deterministic, so nothing changes as you pan away and back. Each plan samples a local height and water grid (`terrain.ts`) at full terrain detail. The grid drives slope-aware layout and shorelines, and draws contour lines whose interval adapts to the relief.

- **Villages** (from zoom 7.5) are placed per 1° block on a jittered ~13 km grid. Placement uses the same habitability score, at full terrain detail, plus bonuses near roads, rivers and coasts. Each village gets a winding track to the nearest road, town or village. Villages come in several kinds, chosen from the site:
  - **Mining camps** in mountains (with enough summer warmth to work).
  - **Logging camps** in forest biomes.
  - **Fishing villages** where there is sea or a lake within ~8 km; the village moves onto the shore.
  - **Keeps** on high ground, climbing to the local summit, and occasionally guarding a road in the lowlands.
  - **Monasteries**, more often in the hills, on a level terrace or knoll above the surrounding ground.
  - Otherwise, **farming villages**.
  - **Army camps** (`frontCamps` in `towns/manager.ts`): where two realms at war today share a border, each side camps a host every 40 km or so along it (about two stretches in three), some 8 km back from the line, on level ground clear of towns and villages. The towns worker builds the world's lore on first use to know its wars (about half a second, once per world). A camp holds 400 to 4,000 soldiers by the size of its realm, is named for its people ("the Varskish War Camp"), and its title names the realm and the war; it is searchable like a village ("1,500 soldiers of the Kingdom of Varsk").
  - **New World villages** are fewer (about two in five of the candidates are kept) and are **tribal villages**, except within 60 km of a colony, where villages are of the Old World kinds. A tribal village (and a New World tribal town, which is built the same way at a larger size) has an open dancing ground with a council house at its heart, longhouses in rings round it with their long sides to the centre, round lodges and drying racks between, a palisade (open at the trails) just outside the houses of the larger ones, and garden plots and forest beyond. The New World has no keeps, monasteries, towers or crypts, and only the odd ruin.
  - **Slope-aware sites** (sampled at full terrain detail, ~60 m): mining camps need real relief and sit on workable ground at the foot of the steepest rise within ~1.5 km (none on flat plateaus); farming villages and lowland keeps move to the flattest ground within ~900 m and are dropped if it is all steeper than 16%; logging camps avoid slopes over ~35%.
- **Markers:** cities show from the globe view, towns from zoom 5, villages from zoom 8, coloured by kind. They fade out as the plans fade in.
- **City and town plans** (from zoom 11.5, `city.ts`) follow [Watabou's Medieval Fantasy City Generator](https://watabou.github.io/city-generator/):
  - **Layouts** (`layout.ts`): each city and town gets one of five layouts, chosen when the world is named from its culture, local relief, river and coast (deterministic per seed); the hover panel shows it.
    - **Round town:** Watabou's sunflower spiral around one market.
    - **Planned grid:** a Roman castrum or bastide on a rotated, slightly sheared lattice with a squared-off core and straight streets; lots are cut at right angles, and the lattice loosens into old field boundaries further out. Most common in Latin and southern cultures, and on flat ground.
    - **Ribbon town:** stretched along the river, shore, valley or through road, with two rows of wards either side of a gently bowed high street.
    - **Hill town:** an uneven spiral (wards of mixed sizes) with a lobed outline; steep ground is kept out of the core much more strongly and streets wind with the contours. Most common on rough ground and in dwarven, Celtic, Elvish and Slavic cultures.
    - **Twin town:** two cores grown together, on opposite banks when a river runs through (big cities only), each with its own market, joined by a Bridge Street.
    The direction a town follows comes from its local ground: the river through it, else the shore, else the through road, else the contours.
  - Wards are Voronoi patches on a sunflower spiral (relaxed once), sized from population.
  - The wall follows the outline of the inner patches, with towers. Gates face the incoming roads.
  - Main streets run from each gate to the central plaza. Roads out to the country bridge rivers but never cross more than 150 m of sea or lake; they go round a bay instead, or are left unbuilt.
  - Special wards: a temple beside the plaza, a citadel with its own wall, and parks. These are laid out in the largest rectangle that fits the ward (`frameIn` in `city.ts`, which tries several centres, the directions of the longer edges and a few proportions, so a ward with a ragged shore still finds its open ground).
  - **Markets:** the plaza holds a fountain (a well in a town) and back-to-back pairs of market stalls in short runs of three to five, with lanes between the rows and cross aisles between the runs; the awnings come in four colours, a run is now and then left out for an open pitch, and a few carts stand at the edges.
  - **Temple close:** the temple, church-proportioned rather than filling the ward, along one side; on a large enough ward a cloister beside it (a green garth with a well and the priests' ranges on three sides), and a graveyard with a hedge, graves and trees beyond the temple's end or beside the cloister.
  - **Holy towns:** a town or city that is one of a faith's holy places (its birthplace, its head's seat, a sect's birthplace, a saint's tomb, a relic's shrine, a holy spring) has a shrine or reliquary beyond the temple's end (a holy spring rises beside it), and a city's temple there is a great temple, up to 66 by 26 m; an inn or more for the pilgrims stands near it. A New World people's holy town has a step pyramid (with the Sky Temple on top) or a ring of totems round a fire at the heart of its dancing ground.
  - **Castle:** within the citadel wall a small citadel is one ward: the keep in a corner, a well, and ranges against the curtain (the great hall, a chapel, barracks, storehouses, stables and a smithy), each placed on the side with the most room left. A large citadel holds an inner ward of that kind behind its own wall and corner towers in the keep's corner, and an outer bailey with a tiltyard, a garden or orchard, and stables, a smithy, barracks and storehouses along the outer wall.
  - Wards are paved (cobbles inside the walls, beaten earth in the suburbs), so the gaps between blocks read as streets and alleys.
  - Wards are cut into small blocks (about two lots deep) with an alley (2.8 to 4.2 m) at every cut, so no block is walled in by its neighbours; contour terraces on slopes are crossed by alleys too. Blocks are then cut into terraced buildings by recursive lot cutting. Every house reaches the block edge (a street or alley); the backs of the blocks are yards (kept 3 m back from the water, and left out on harbour quays and beside piers, where only warehouses stand, clear of the pier ends). Slivers, scraps and triangles too thin to build on are left as yard. Wedge-shaped and triangular lots (less than 72% of their smallest bounding rectangle, `squareUp` in `city.ts`) take the largest rectangular house that fronts the street on the lot's street edge, with the rest left as yard; nearly rectangular lots keep their full shape, so terraces keep an unbroken street front.
  - Suburbs are small blocks with lanes between them: houses front the lanes, gardens fill the backs, and blocks away from the road stay as meadow.
  - Outside the walls are suburbs along the roads, then fields with furrows, orchards and meadows.
  - Sea, lakes and rivers (at their true width) carve the plan; streets crossing a river become bridges.
  - **Terrain:** the walled core grows onto the gentlest nearby ground. Street routing penalises steep grades. On slopes, blocks are cut into terraces along the contours, and ground too steep to build on is left wooded. The citadel and temple take the high ground.
  - **Harbours** (`harbour.ts`): along the waterfront, piers (some with T-heads) reach out to open water, with boats moored alongside. Shore wards become warehouses, cities get a lighthouse and ships at anchor, and river towns get short jetties.
- **Fitting plans to the ground** (`ground.ts`): every plan gets a usable-ground test built from its local terrain grid (distance to water by chamfer transform, slope, and the exact shoreline near the water).
  - **Barrier seeds:** field Voronoi diagrams get extra seeds just past the edge of usable ground (shores, river banks, steep crags) whose cells are discarded, so the neighbouring fields end along the shore in short irregular steps, as on a hand-drawn map.
  - **Fitting:** fields, meadows, yards, paving, parks, plazas and the citadel are densified, and each vertex is pulled in to the last usable point on its ray from the centre (marched outward in steps that stride by the distance to water), so inlets and ponds reaching into a polygon are cut out too; vertices end on usable ground (at least 4 m from water for fields), with inward-only smoothing and a slight hand-drawn wobble; furrows are clipped to the fitted outline. Buildings and lots are kept only if every corner is on dry, workable ground.
  - **Terraces:** on gentle slopes (6–14% in villages, up to 20% around towns) fields are cut into strips along the contour, with furrows following it.
  - **Hedgerows:** some fields and meadows get a dotted hedge outline.
  - **Walls** are walked in short pieces, so they stop at the shore with a tower instead of crossing a bay between two corners.
- **Village plans** (from zoom 12.5, `village.ts`, shared pieces in `kit.ts`) Buildings stay off ground steeper than 35% and turn to run along the contour on hillsides; fields on slopes over 14% become pasture, and over 25% are left wooded. Each kind has its own layout:
  - **Farming:** winding lanes from each track to a common centre with side lanes, a village green (or, in villages of 300 or more, a market square with stalls) where they meet with the **well** at its heart, houses facing the lanes (densest at the centre), a chapel in larger villages, a **mill** in villages of 120 or more (a watermill on the river bank with its wheel in the stream, and a track out to it, where a river runs within the plan; otherwise a windmill with its sails on the highest open ground just outside the village), Voronoi fields with furrows cut by the lanes, and trees in clumps and gardens.
  - **Fishing:** houses crowd down to the shore, with jetties, moored and beached boats, paths to the water, a green or market square with its well, and a few fields inland.
  - **Logging:** a clearing in dense forest with a sawmill (on the river bank if there is one), stacked logs, stumps and a few cabins.
  - **Witch's huts:** about one Old World farming, fishing or logging village in five has a witch's hut, a hedge-witch's or wise-woman's house or a cunning-man's cottage out beyond the fields, in a stand of trees, with an herb garden and a footpath from the nearest lane. Inside: a hearth room with a cauldron, an herb room, a bedroom, a drying loft and a root cellar.
  - **Army camp:** a marching camp facing the road, ringed by a ditch and a palisade with a gate in each side; two camp streets cross at the commander's pavilion, rows of tents fill the quarters, one quarter holds the horse lines, supply wagons wait outside a gate, and the ground is trampled bare all round.
  - **Mining:** adits up the slope with cart tracks, spoil heaps, a smelter and huts.
  - **Monastery:** a walled compound with a church, a cloister around a garth, ranges, vegetable beds and an orchard, surrounded by fields.
  - **Delves** (`delveGate` in `village.ts`): the cities and towns of an underground people (Dwarves, the `underground` flag of their bundle) that stand above 650 m or on steep ground (about 85% of them) are delves: their halls lie under the mountain. On the map stands only the great gate, cut into the rise and facing the road: the gatehouse between towers, a wall across the rock face, carved guardians either side, a paved forecourt with a well, and the works that need the open air along the road among heaps of slag, growing with the delve (a smelter for every 8,000 people or so, stables, the Gate Inn and in a great delve a second inn, storehouses, and up to eighteen houses). Behind the gate, the delve's districts under the mountain are outlined faintly on the plan, fanning out up the great avenue, each lettered with its name. The gate opens the delve's map (see **Dungeons**). The title says the town is a delve, and delves take no city theme.
  - **Shrines** (`shrine` in `village.ts`): each faith's natural holy places (a holy peak or mountains, a sacred lake, a holy forest or isle, see **Faith**) get a shrine on the ground: on the summit, on the nearest level shore of the lake, or on level ground in the forest or on the isle, with a track to the nearest road (a village standing on the spot makes way). In the Old World a ring of standing stones round a level green with an altar stone, a chapel with a keeper's cell, a pilgrims' lodge, an herb garden and a holy well, or a hermitage (monotheist faiths favour hermitages on peaks and isles); in the New World a ring of carved totems round a fire with a few lodges, or a step pyramid in a paved court with its priests' houses (sun and serpent peoples: Jungle, Highland and Saurian). Shrines are named for the place ("the Stones of X", "X Hermitage", "the Pyramid of X"), marked in gold, searchable, and their title names what is holy there and the faith that keeps it.
  - **Keep:** a ringwork on the hilltop with a ditch, a wall with towers and a gate, a keep tower and hall, and a hamlet along the approach.
- **City themes** (`lore/themes.ts`): about three Old World cities in ten take one theme, chosen from the lore so it fits (each theme scores the city from its realm, culture, ground, trade, wars and faiths; the strongest wins if it is strong enough, with a little chance in it). The theme and the reason show in the city's title ("a fortress city (it guards the front of a war)"), and searching for a theme ("merchant city", "forge city") lists them.
  - **Merchant city** (rich ports and river towns, above all in republics, city-states, thalassocracies and leagues, and among Merchant Princes and Seafarers): a second market beside the first, both fuller (closer rows of stalls), a counting-house quarter round them with banks and counting houses ("Korengo Bank"; a counting room, strongroom and clerks below, a vault in the cellar), the halls of the merchant companies (Drapers', Vintners', Mercers'), and more piers and warehouses on the waterfront.
  - **Canal city** (river mouths among marshes, mangroves and lagoons): canals take the place of some of the lesser streets, from points spread through the city to water gates (a tower either side) where the wall meets the water, to the river or shore, or to another canal; the houses stand back on quays, and bridges carry the main streets over them.
  - **Thieves' city** (great cities, poorer, unruly or at war, without a stern faith or law): a rookery on the low ground by the water or the wall (narrow alleys, crowded small houses and tenements, beaten earth), more dives and pawnshops, and below it a larger, richer thieves' guild: a fences' market and the guildmaster's rooms besides the hall, vault and quarters, and twice the chests of loot.
  - **City of mages** (university cities, elves, and inventive, star-reading or courtly peoples): a mages' tower (four or five storeys: library and hall, laboratories and studies, an observatory at the top, a summoning chamber below) in a walled garden on the high ground, a university, and the Mages' and Alchemists' guilds.
  - **Forge city** (dwarves, and realms with metals in their hills, Master Craftsmen and Deep Delvers): a forge quarter by a gate full of smithies, armourers and foundries, the Smiths' Guild, slag heaps beyond that gate, and water mills on the river banks to drive hammers and bellows.
  - **Fortress city** (walled cities within about 120 km of a front in today's wars, and bellicose or warlike peoples): a second, outer wall some 26 m beyond the first and gated with it (no houses between), a citadel even where none was planned, two more garrison wards by the gates, and the Warriors' Guild.
  - **Pilgrim city** (holy cities, see **Holy towns** above): the great temple with its shrine, a pilgrims' square of stalls beside the temple close, and three to five pilgrims' inns ("the Scallop Shell").
  - **City rebuilt** (counties won or lost in a war of the last 400 years): a ruined quarter never rebuilt, of roofless shells, rubble and trees, inside the walls.
- **Names** (`naming.ts`): every settlement and village has a name in its culture (keeps, abbeys, mines and camps get fitting forms such as "Castle X" or "X Priory").
  - **Quarters** grow over the ward adjacency graph from spread-out seeds and are named after what they hold (Old Town, Castle Quarter, Harbour Quarter, Temple Quarter, Market Quarter, the Heights, gate quarters, craft quarters); suburbs are named after their gate.
  - **Districts:** the market, temple (dedicated to a named deity), citadel, garrison, harbour, parks and graveyards are labelled.
  - **Garrison and graveyard:** walled cities and towns over 2,500 people get a garrison ward with barracks and a drill yard by the citadel or a gate; some cities turn a park or wall ward into a graveyard with a hedge and rows of graves.
  - **Streets:** main streets are named (High Street, gate streets) and roads leaving town are named by direction.
  - **Notable buildings** get a role and a label: inns and taverns (with generated signboard names), moot hall, the merchants' guildhall, library, smithy, bakery, apothecary, pawnshop, tailor, butcher, stables, bathhouse, chandlery and fishmonger; villages get an inn, smithy, apothecary (over 260 people), chapel and churchyard, a watermill or windmill (millstones and grain floor inside), sawmill or smelter. Labelled buildings are tinted on the plan. Halls take a building from the larger half of the town's. **Guilds** (`GUILDS` in `towns/naming.ts`): towns of 4,000 or more may have one guild, cities two (under 10,000), three or four (under 20,000) or four to six, chosen by weight from the Adventurers' Guild (by a gate), the Warriors' Guild (by the garrison or castle), the Cartographers' Guild (by the harbour), the Alchemists', Masons', Weavers' and Physicians' guilds (by the market), the Smiths' Guild (by a gate) and the Mages' Guild (in a rich ward; cities of 15,000 or more, or university cities). Their interiors follow the guild: a common room and notice hall with bunk rooms above, a training hall and armoury, a map room and drafting room, a laboratory and still room, a lecture hall, laboratory, library and a summoning chamber in the cellar, an infirmary. The thieves keep no hall: their guild hides in the sewers. A **university** city has its great hall ("the University of {Town}": lecture halls, a disputation hall, libraries and an observatory) near the temple or market, with two to four colleges around it (refectory, master's lodging, scholars' rooms and a dormitory).
- **Styling** (`components/map-style.ts`): plans are vector layers drawn in true metres (each feature carries its pixels-per-metre at zoom 20). Roads and streets share one width expression, so world roads join the plan roads seamlessly. The map zooms to 20 (~0.15 m/pixel).

## Building interiors (`src/interiors/`)

Every building on a town or village plan has a deterministic interior in the manner of [Watabou's Dwellings](https://watabou.github.io/dwelling.html), generated on demand from its footprint, its context and the world seed (`dwelling.ts`).

- **Tagging:** plan buildings carry an id, their settlement, tier and context (ward kind in towns: ward, rich, harbour, suburb, farm; or the village kind) and, where known, the direction of their street front (the lot edge on the block's street, the nearest road, or the village lane).
- **Grid:** the footprint is laid on a 1.5 m (5 ft) grid turned so the street front is at the bottom. Convex footprints (nearly all lots) keep their true outline: the plan is clipped to it and its edges are the outer walls, so slanted lots keep their shape. Furniture and stairs stay on whole cells.
- **Type:** cottage, farmhouse, town house, mansion, warehouse, temple, keep, hall, storehouse, mill, monastic range, cabin or miner's hut, from the building's use and context. Labelled buildings use their role instead: inns and taverns (taproom, kitchen, guest rooms), civic halls, libraries, barracks, stables and bathhouses get their own programmes, and shops put the matching trade room on the street. The view's title shows the building's name. The type sets storeys (with storey heights), the chance of a basement, and the roof (gabled on rectangles, hipped otherwise, flat with battlements on keeps).
- **Rooms:** a binary partition of the footprint shared by every storey, so walls line up floor to floor. Each floor's programme (for a town house: hall, a shop, workshop, smithy, bakery or taproom on the street, kitchen at the back, pantry, parlour; bedrooms and a landing above) is assigned to the partition by preference (the stair, front, back, large, small). Temples get a nave between aisles, a sanctuary, vestry and porch, and side chapels off long aisles; keeps a guardroom, armoury, kitchen, well room and storerooms, a great hall, the lord's chamber, solar and chambers, and a dungeon with five cells. Cellars are one vault.
- **Stairs:** one stairwell through every floor (a ladder to cottage lofts, a spiral stair in keeps), placed under the ridge when there is an attic. The attic covers the cells with at least 1.7 m of headroom under the roof.
- **Doors and windows:** a spanning tree of doors from the entrance (or stairwell) plus the odd extra door, a front entrance on the street side and sometimes a back door; windows along outside walls with piers between them (front and back only in terraced town houses, gable ends in attics, arrow slits in keeps, none underground).
- **Furniture** by room: beds, chests, wardrobes, hearths and ovens on outside walls (with chimneys above), tables with chairs, great halls, refectories and mess halls set with a high table and rows of trestles and benches, dormitories and barrack rooms with as many beds as the room holds, fonts and well heads, counters, workbenches, shelves, bookcases, barrels, crates and sacks, pews and an altar, tombs in a crypt, straw in the cells.

- **Building styles** (`style.ts`): every building on a plan carries its people's culture template (`cul`), and the exterior is built as they build. Walls: timber-framing (Anglic, Germanic), dark upright boards (Nordic, Japonic, Woodland, Islander), round logs (Slavic, Orcish), rough or pale stone (Celtic, Highland, Elvish, Dwarvish), ochre or white plaster and whitewash (Latinate, Southron, Koreanic, Indic, Zanji, Jungle, Halfling), grey brick (Sinic), and mud brick (Desert, Sahelian, Steppe, Saurian). Roofs: thatch, red tile and pantile, slate (green-grey among the elves), shingle, turf (Nordic), bark (Woodland, Orcish), palm thatch (Jungle, Islander, Saurian), grey glazed tile with eaves that sweep up at the corners on hipped roofs (Sinic, Japonic, Koreanic), or flat roofs of beaten earth or plaster behind a low parapet (Desert, Sahelian, Zanji, Indic, Steppe). Some peoples pitch their roofs steeper (Nordic, Germanic, Celtic, Slavic, Elvish, Highland, Jungle) or gentler (Latinate, Southron, Dwarvish). Cottages may differ from town houses (thatched Anglic cottages), and keeps, temples, warehouses and other great halls keep stone walls under their people's roof (a flat-roofed people's temples are still roofed).
- **Burrows** (`burrowLeaves`): a burrowing people's houses (Halflings, the `burrows` flag of their bundle) are burrows: on the plan each house is rounded off and set on a grassy mound with a turfed roof; inside, a passage runs down the middle from the round front door, with the parlour and kitchen nearest the door, then pantries, the dining room, larders, a study and the bedrooms off either side, and often a root cellar below. The exterior shows a domed turf roof, low green walls, round windows and a round green door with a brass knob.

Views (`render.ts`, `building.ts`, `components/DwellingView.vue`):

- **Hover preview:** from zoom 17, the ground floor is drawn into an image placed over the building's footprint on the map.
- **Dwelling view:** double-click a building (or tap it twice) to open a full-screen view with a tab per floor (basement, ground floor, upper floors, attic or loft) and an **Exterior** tab. Plans are inked in a hand-drawn style with a 5 ft grid, room labels, a north arrow and a scale bar; Labels and Grid can be turned off, and **Download PNG** saves the current view for use as a battlemap. The exterior is an isometric drawing: the walls with the plans' windows and doors, gable ends, the roof (by the building's people, see **Building styles** below) shaded by slope (hip roofs as one plane per wall, so their hips and ridge are sharp, with courses of tile or thatch along the eaves), and chimneys over the hearths. **Leave building** or Esc returns to the map; the arrow keys change floors.

## Realms, arms and the location title

- **Political map** (`gen/politics.ts`), built from the bottom up after naming, in five tiers:
  - **Baronies:** every city and town seats a barony over the land nearest it by travel cost (a Dijkstra from all seats at once, cities reaching further). Climbs and high ground, crossing a big river (order 5 and up) and the sea (impassable) all count, so borders follow ranges and rivers. Land more than ~300 km (towns) or ~420 km (cities) of travel from any seat stays unclaimed. A barony seated in a city is styled a City (with a Lord Mayor, Podesta, Wali or the like). Keeps and monasteries, which are placed later with the villages, are named in the location title as baronial holdings and abbey lands within their barony.
  - **Counties** gather baronies around the larger seats at least ~95 km apart (about two or three baronies each); **duchies** gather counties around the strongest seats at least ~300 km apart (a duchy needs two counties); **kingdoms** gather duchies, and the counties and baronies left between them, around duchy seats ~600 km apart; **empires** are rare: two or three in the Old World, formed around the greatest kingdoms (by estimated people, weighted towards Latin, desert and Sinic peoples, and of different peoples where possible) that can gather at least three realms, two of them kingdoms, and perhaps one in the New World (most likely among Highland peoples). Realms of the Old and New Worlds never mix. In the Old World of a 1024-wide world the median barony is about 7,600 km², county 19,000 km², duchy 140,000 km² and kingdom 530,000 km² (France is about 550,000 km²). Each liege claims by the same travel cost, now across some sea and with a toll for crossing into another culture at the higher tiers; each vassal goes wholly to the liege that reaches its seat.
  - **Independent realms at every tier:** whatever no liege gathers stands alone, and some stand apart by choice: **city-states** (cities of 6,000 or more, most often in the south, sometimes with the towns within ~110 km as their territory), **prince-bishoprics, abbacies and imamates** (a few counties held by the church), and **grand duchies** (likelier among southern, Latin, elvish, dwarven, jungle and steppe peoples; rare among Norse, Slavic and Celtic peoples, who keep to kingdoms). On a 1024-wide world this gives about 5,000 baronies, 2,300 counties, 500 duchies, 110 kingdoms and 2 or 3 empires, with kingdoms the commonest independent realm (about 80, beside some 85 city-states and 60 others).
  - **Governments:** independent realms of duchy size and up may become a **republic** (above all in the south, then among Latin, Anglo and dwarven peoples), a **theocracy** (more often where the people's faith has a head of faith, a zealous one, or is the faith of the prophets; fewer where its rulers are sacred kings already; named and styled by the faith it serves: a Prince-Bishopric, Abbacy or Holy See for a church, an Imamate or Caliphate for the faith of the prophets, a Druidry, Temple-lands, Rune-hold, Celestial Realm, Sun Realm and so on), or, for island realms and realms spread over several landmasses, a **thalassocracy** (Thalassocracy, Sea Kingdom, Admiralty, Maritime Republic).
  - **The New World** is tribal: its towns seat bands, gathered into chiefdoms, tribes, nations and (rarely) an empire, styled by culture: Woodland (the X Band, X Clan, the X Tribe, the X Nation; Headman, Chief, Paramount Chief, Great Chief), Highland (Valley of X, Lordship of X, the X Realm, Empire of the X Sun; Lord, High Lord, Sun King, Child of the Sun) and Jungle (City of X, Kingdom of X, the X Overkingdom; Holy Lord, Overking, Great Speaker). Woodland nations band readily into confederacies (the X Confederacy, under a Council of Chiefs). Land beyond the towns is named in the title as the tribal lands of the woodland, highland or forest peoples.
  - **Colonies** are held from overseas: each colony town's barony sits under a colony (Colony of X under a Governor, the Garrison of Fort X under a Commander, the Trading Post of X under a Factor), held directly by the largest Old World realm of its founders' people (or, failing one, the nearest), whose colour it takes on the political map and whose people and land it adds to.
  - **East Asian styles:** Sinic baronies and counties are counties and prefectures (Magistrate, Prefect), duchies provinces (Governor), empires dynasties ("the X Dynasty", "Middle Kingdom of X"); Japonic fiefs, domains under a Daimyo, provinces under a Shugo, and shogunates under a Shogun; Koreanic hyeon and gun (Magistrate, Gunsu), provinces ("X-do") and kingdoms.
  - **People:** every unit estimates its people from its land: town-dwellers plus about 8 country people per km² of fully habitable land in the Old World (1 in the New), weighted by biome (grassland, temperate forest and river valleys in full, savanna and shrubland at 60 %, boreal forest a third, deserts and tundra hardly at all). The title and search show it ("about 12 million people"), with the town-dwellers in the hierarchy panel.
  - **Leagues and confederacies:** three or more small independent neighbours (city-states, free counties, duchies and republics within ~650 km) may band together, most readily in the south (the Amphictyony of …, the … League), among Norse (Hanse), steppe and Celtic peoples (Confederacy). Members keep their own rulers and arms; the league has a council (Synedrion, Allthing, Kurultai, Diet, Council), a seat, arms of its own, a name on the map and a dashed blue-green line round the union.
  - **Styles and rulers** follow the culture and tier: Barony, Herad, Timar, Volost, Tuath, Deme or Ulus; Earldom, Jarldom, Beylik, Zhupa, Cantref or Archonate; Duchy, Principality, Emirate, Voivodeship or Khanate (Grand Duchy for some independent duchies); the culture's kingdom styles; Empire, Imperium, Caliphate, Khaganate or High Kingdom. The ruler follows the style (a Sultanate has a Sultan, a Herad a Hersir) or the government (a Doge, an Archon, a Prince-Bishop, an Imam, a Thalassarch). Kingdom names drawn from a culture's `realm` list skip the styles that now belong to a government or another tier (republics, leagues, empires, counties, duchies).
  - Worlds wider than 1024 work out realms on a 1024 × 512 copy of the grid (realms are hundreds of km across, and the borders are smoothed anyway).
- **Borders** are traced along the grid between cells of different realms. Within a realm each line is drawn once at the highest level that differs; between independent realms it is drawn at the higher of the two realms' levels (at least a duchy's line). Lines are relaxed out of their staircase (Laplacian smoothing), rounded (Chaikin) and simplified. Empire and kingdom borders are inked dash-dot and dashed over a soft red wash; duchy borders appear from zoom 4, county borders (dotted) from zoom 6, barony borders (fine dots) from zoom 8; league borders are long-dashed in blue-green. Realm names are lettered in red small capitals (empires from zoom 1.4, kingdoms from 2.9, duchies from 5.2, counties in italic from 7.2, baronies from 9.4); leagues in blue-green italic from 2.6. Independent small realms are lettered a size up (a city-state like a duchy, an independent duchy like a kingdom), and every independent realm, kingdom, empire and league carries its arms above its name.
- **Heraldry** (`heraldry/arms.ts`, `heraldry/draw.ts`): a shield shaped by culture (heater, round, kite, French or Spanish); a field of a metal (Or, Argent), a colour (Gules, Azure, Vert, Sable, Purpure, Tenné, Sanguine, Celeste) or a fur (Ermine, Vair); plain, divided (per pale, fess, bend, bend sinister, saltire or chevron, or quarterly) or patterned (paly, barry, chequy, gyronny); an ordinary (fess, pale, bend, chevron, cross, saltire, chief, pile, pall or bordure); and one, two or three charges (mullet, crescent, roundel, lozenge, tower, crown, fleur-de-lis, key, tree, sun, cross pattée, anchor, lymphad, sword, hammer, axe, eagle displayed, wheel, bell, hunting horn, estoile, heart, acorn, lion rampant, triple-towered castle), keeping the rule of tincture. Charges on a divided field are counterchanged; patterned fields carry theirs on a chief. Each culture favours some charges (Anglic and Teutonic peoples lions, castles and anvils; dwarves anvils, castles, hammers and axes; Celts triskeles, the red hand and harps; Norse ships and axes; Slavs eagles; Zanji ships, a hide shield with crossed spears, and the lion), and governments too (theocracies crosses and keys, sea realms ships and anchors, city-states towers and keys, leagues several charges). Arms descend: a vassal keeps its liege's field and colours with a new charge, reversed colours or an added ordinary; a junior house (a barony under its county, a county under its duchy) adds a bordure or label; a realm and its seat share arms; empires are crowned. Towns take arms derived from their barony's. Each comes with its blazon ("Barry of eight Vert and Or, on a chief Argent three suns Sable").
- **Emblems of other cultures** (`STYLE_BY_CULTURE` in `heraldry/arms.ts`, drawn in `heraldry/draw.ts`): not every people bears a European shield. **Woodland** realms bear a painted round hide shield with a laced rim and five hanging feathers; **Highland** a square emblem with a border of small squares and a stepped cross with the charge in its heart; **Jungle** a rounded glyph block with a stepped-fret band below and a dot for each charge; **Japonic** a round mon, one colour on another within a ring (three charges wheel about the centre, as in a triple tomoe); **Sinic** a square seal with a double frame and key-fret corners; **Koreanic** a banner on a pole with a spear finial, fringed with flame points; **Desert** a round blazon of three bands with the charge on the broad middle one; and **Steppe** a brand mark (tamga) on a disc hung with horsetails, built from the arms' seed: one of four base forms (a stem, a ring on a stem, an arch with a stem, or a zigzag), a head and a foot, and at most two side strokes. These emblems take no ordinaries or furs, and only some divide their field (hide shields halved or quartered, glyphs and banners halved). Their peoples favour their own charges, among them some found only there: the tomoe, folding fan, ring of hollyhock leaves and seigaiha wave (Japonic), the cash coin, lotus and taiji (Sinic; the lotus also Indic, the taiji also Koreanic), the horse's head and the recurved bow (Steppe), the feather, the bird volant, the serpent and the cloud. Vassals difference their liege's emblem by a new charge or swapped colours (a tamga gains a stroke of its own on its liege's mark), junior houses by a coloured ring or mark, and empires take a gold frame in place of a crown. Arms descend in their liege's form, so a colony keeps its founders' European arms. The blazon names the form first ("A mon: Celeste, a blossom Argent").
- **Political map** (`world/political.ts`; the **Political map** checkbox): raster tiles drawn on the main thread from the political grid through a `politics://` tile protocol. Each independent realm gets a colour from a twelve-hue watercolour palette with no greens or yellows (they would vanish into the map's meadows and deserts), chosen largest realm first as the hue furthest from its neighbours' hues (league members lean to their league's hue where it stays clear of their neighbours). Up to zoom 5 a realm is one flat colour; from zoom 5 its duchies, and from zoom 8 its counties, show as lighter and darker shades of it. Cells along a realm's edge are washed deeper, and colours are blended between grid cells, so edges are soft rather than stepped. The wash is strongest zoomed out (85 %) and fades as you zoom in (55 % at zoom 6.5, 25 % at 9, gone by 11.5), leaving the borders and the internal divisions' labels. While it is on, every independent realm is lettered larger in dark small capitals (larger still for larger realms) under its arms drawn at about twice the usual size, leagues likewise in blue-green italic; these replace the usual empire, kingdom and league labels and the labels of independent small realms.
- **Location title** (`components/LocationTitle.vue`): a cartouche at the top of the map names where the map centre is, at the scale you are looking at: the empire (or the highest realm there) when zoomed out, the kingdom from zoom 4.3, the duchy from 6.3, the county from 8.3 and the barony from 10, with its arms, its ruler and seat, its kind of government (for independent realms and kingdoms), its vassals by tier ("5 duchies, 2 counties", or a league's members), the land region it lies in, and the realms above it (and the league) as a breadcrumb with small arms. From zoom 11 it names the city, town or village under the centre (with population, layout and the realms it seats; for keeps and monasteries, the barony they belong to); over the sea it names the sea, in unclaimed land the wild region. Click its name or arms to open the realm's details (a breadcrumb opens that liege); the arrow beside it lists the whole hierarchy with larger arms, government, area, people, vassals and blazons, each row opening its realm. Realms are searchable too, by name or kind ("league", "republic", "city-state"), and choosing one opens its details as the map flies there.

## Realm details (`src/lore/`, `components/RealmView.vue`)

Click a realm's name or arms on the map, the location title, or a realm in search to open a panel beside the map (a sheet from the bottom on phones) about that realm, at any tier from barony to empire, and for leagues. The header gives the realm's name and its ruler's title in the rulers' own language. Every realm named in it opens in turn; **Back** returns, **Show on map** flies there. All of it is seeded from the world, so a world always tells the same story. The world's lore is built on first use (about a third of a second for a 1024-wide world); each realm's details on demand, in a few milliseconds.

- **Calendar and great events** (`lore/world.ts`): the present year (between 880 and 1440 of a named era, "after the Flood", "of the Reckoning"), one to three plagues that swept the Old World ("the Grey Death"), a great comet, and, when there are colonies, the Age of Sail. Each realm was founded in a seeded year by tier and government (empires after the kingdom at their heart; colonies after the Age of Sail), and each vassal joined its liege in a year and by a manner (conquest, marriage, inheritance, oath of fealty, submission).
- **Rulers and houses** (`lore/names.ts`, `lore/realm.ts`): hereditary realms have one to five ruling houses over their history, changed by usurpation, conquest, rebellion, marriage, election or the old line dying out; vassal counties and baronies are often held by cadet branches of their liege's house. Each reign has a ruler with a given name in the culture's manner (family name first in Sinic, Japonic and Koreanic lands; patronymics among Norse, desert and Celtic peoples; "son of" among dwarves), traits, often an epithet, a regnal number when a name repeats, how they came to the throne and how the reign ended (old age, battle, murder, plague, deposition). Republics, city-states and theocracies elect their leaders from leading families (priests take holy names); colonies have appointed governors; leagues a council. The current ruler shows age, traits, spouse (from an allied house when a marriage seals an alliance), heir or heir presumptive, a regent for a child ruler, the culture's law of succession, and a court of named officers by culture (Chancellor, Grand Vizier, Logothete, Master of Whispers, Forgepriest). A unit held in person by its liege shows the liege's ruler.
- **Diplomacy** (`lore/world.ts`): neighbours are realms that share a border (or coastal realms within ~900 km by sea). Past wars between neighbours are seeded through history, each with a name ("the War of Xulmopan", "the Hundred Years' War", "the Holy War"), a cause, a peace or treaty and an outcome consistent with today's map: a county won is held by its winner now, and its loser claims it still for two centuries. Relations come from shared faith and sect, shared culture, recent wars and claims: alliances (often sealed by marriage), friends, rivals, truces after recent wars and a few wars today (about one realm in thirty), with allies called to arms; rivals of one realm tend to ally against it. Houses that lost a throne by usurpation, conquest or rebellion may leave a pretender, sheltered at a rival court. Vassals show their realm's foreign affairs.
- **Vassals:** a tree of the realm's vassals, largest first, each with its ruler, people, how and when it joined, and unrest (a vassal of another people, or one claimed by a foreign power); rows open to their own vassals. Leagues list their members.
- **People:** people, town-dwellers, density, the mix of peoples (from the land's cultures, weighted by habitability), folk (each culture's own: humans, elves, dwarves, halflings, orcs or lizardfolk, with a few gnomes, half-elves, half-orcs, goblins and others by culture; many folk from across the world among cosmopolitan peoples, hardly any among insular ones, and humans only when fantasy races are off), faiths (with dissenting sects), the largest cities and towns and estimated villages.
- **Trade and arms** (`lore/economy.ts`): the land is summed from per-barony statistics the world worker records (`RealmStats` in `gen/politics.ts`: area by biome, habitable area by culture, coastline, uplands, mean temperature and rain, and which baronies border which). Goods follow from them (grain, rice or maize, cattle, fish, salt, timber, wool, horses, furs, iron and stone, wine and olive oil in their climates, spices, sugar, cotton, dates, incense, ivory, tea, silk, pearls, amber, whale oil, honey, dyes and cacao, and by luck silver, gold, copper, tin and gems in the mountains), scaled by how much of the land its people work. Exports are goods the realm makes far more of than its share of the world's people; imports are staples it lacks and, for rich realms, luxuries. Trading partners are realms whose exports meet its imports, nearer (and by sea, much nearer) counting for more. Each realm is known for a named craft of its culture ("Jidid rosewater", "Kumkent composite bows"). Wealth ranks it among all independent realms, with a revenue in its coin (crowns, florins, dinars, taels, ryo, cacao beans). Armies: levies, standing troops, mounted share, ships of war (more for sea powers), walled towns, the culture's way of war and, for many realms, a knightly order named for the charge in its arms.
- **Faith** (`lore/faiths.ts`): faiths are generated from thirteen familiar **archetypes** (a monotheist church, the faith of the prophets, a pantheon, the old gods, druidry, the stars, the forge and the ancestors, the eternal sky, the way of heaven, the spirits of place, the Great Spirit, the sun and the feathered serpent). The mix: every **language family** begins with a **native faith** shaped by its largest people's template (the old gods for Anglic, Nordic and Slavic stock, a pantheon for Latinate, Southron and Desert, druidry for Celtic, and so on), named in its proto-language: its name, gods, head's title and scripture are made in English and translated ("the Old Custom", *Star Na*); sister peoples keep it as rites of their own. Then one to three **missionary faiths** are founded by a prophet among Old World peoples (a church among Latinate, Southron, Anglic, Slavic, Celtic or Nordic peoples, the faith of the prophets among Desert or Steppe peoples, a way of heaven among Sinic, Koreanic or Japonic ones; founders at least ~1,800 km apart), 450 to 1,100 years ago, and spread: each Old World people takes up the nearest missionary faith that reaches it, with a chance falling off with distance (further for faiths with Mendicant Preachers or conversion by the sword; kin of the founders more readily; elves and dwarves seldom), in a year that grows later with distance. The old faiths of converted peoples live on as minorities in their realms, and a faith whose peoples have all converted lives on among holdouts. Which faiths exist, who keeps them and each faith's doctrines and tenets are planned from the seed and the cultures alone (`faithPlan`), so world generation (theocracies and their styles) and the lore agree; names, gods, sects and holy places are added in the lore. Each faith has **doctrines** (head of faith: a high priest, sacred rulers or none; clergy: celibate, married, priestly houses, priestesses or open; conversion: missionary, closed or by the sword; other faiths: pluralist, righteous or fundamentalist; the dead: burial, burning, barrows, tombs, sky burial or the sea; marriage) and three **tenets** in the manner of Crusader Kings (Holy War, Pilgrimage, Alms, Monastic Orders, Mendicant Preachers, the End of Days, Sacred Law, Aniconism, Ritual Purity, Ritual Sacrifice, Divination, Great Feasts, Sacred Hospitality, Astrology, Warrior Paradise, Sacred Groves, Sacred Waters, Sanctity of Nature, Rebirth, Ancestor Veneration, Sacred Kingship, Asceticism, Pacifism, Craft as Worship, Dualism), chosen by the archetype's leanings. Doctrines and tenets give each faith a **zeal**: zealous faiths fight more wars, more of them holy wars (judged by the faiths the two sides kept in the year the war began), and keep colder relations with other faiths; pluralist faiths make realms tolerant, fundamentalist ones harsh. Each faith has gods or holy figures with their domains (named in its tongue, never with familiar real-world names), teachings, clergy, temples, scripture, symbol, a head seated at a theocracy's capital or its birthplace, sects (rites of sister peoples for native faiths; schisms that differ in a doctrine, "holds that priests may marry", for missionary ones, founded after their people converted), and holy places: its birthplace, its head's seat, the birthplaces of its sects, up to two of the map's own peaks, lakes, forests or isles near its home (by archetype), and holy cities. Realm chronicles tell of the prophet's first preaching, a ruler's conversion (by missionaries or by the sword; the old shrines left standing, closed or thrown down by the faith's view of others), schisms taken up and pilgrims to holy cities.
- **Chronicle:** a dated timeline of the realm's founding, notable successions (new houses, child rulers, murders, deaths in battle and of plague), wars and peaces, marriages and alliances, vassals gained, conversions and sects taken up, the world's great events, and a few local ones (a cathedral consecrated, walls raised, a great fire, famine, flood, a dragon slain, the dead walking in the marches).
- **Faith map** (`prepareFaithMap` in `world/political.ts`; the **Faith map** checkbox): `faiths://` raster tiles washing each barony in the colour of the faith its people keep (by its culture and the nearest sect), coloured largest faith first as the hue furthest from neighbouring faiths' (and least used); from zoom 5 sects show as lighter and darker shades, with deeper edges between faiths and lighter ones between sects. Holy places are a GeoJSON layer of dots in their faith's colour.
- **Culture and race maps** (`prepareGroupMap` in `world/political.ts`, which the faith map shares; the **Culture map** and **Race map** checkboxes): `cultures://` and `races://` raster tiles washing each barony in the colour of its people (chosen as the faith map's are) or of its people's race (a fixed colour for each race, shaded by people from zoom 5). Each people's name stands at the barony nearest the middle of its lands (a spherical mean, so lands across the date line are handled); smaller peoples are named from zoom 4. Built from the world's politics and cultures alone, so they show at once.
- **On the map** (`setRelations` in `world/political.ts`): while a realm is open, `relations://` raster tiles tint its own lands gold (the rest of its realm, for a vassal, pale gold), allies and league fellows blue, friends pale blue, realms at truce grey, rivals orange and enemies at war red with hatching, with deeper colour along their edges, fading out by zoom 13; dashed lines run from its capital to its trading partners'. A key (`components/RelationsLegend.vue`, bottom left; collapsed at the top left on phones) explains each colour and lists the realms in it (each opens its details), with the number of trade routes; the faith map's key gives way to it while a realm is open.


## Faith window (`components/FaithView.vue`, `lore/faiths.ts`)

Click a faith in a realm's Overview or Faith tab, a culture's Overview, or search for one by name (faiths join the search once the world's lore is built, when the page is idle), to open a panel about it. **Overview:** an account of its founding (by a prophet, or among a family's ancestors), the peoples who keep it and once kept it, its realms, its zeal, the faithful, its head, scripture (with its name in the holy tongue), clergy and temples, the realms that keep it (each opens its details) and its holy places (each flies to the map). Beside its name stands its **emblem** (`lore/emblem.ts`), drawn in SVG as heraldry is: a field shaped by its archetype (a roundel, octagon, hexagon, lozenge, vesica or stepped square) in a tincture, a frame (rays, a ring of dots for its gods, laurel, knotwork, an eight-pointed star, or its name in its holy script around the rim), its symbol as the core motif in a metal (about eighty symbols, from a crescent and star to a feathered serpent), and a small mark of one of its tenets (crossed swords for holy war, stars for astrology, waves for sacred waters, an olive branch for pacifism, leaves for sacred groves). **Doctrine:** its doctrines, tenets (with what they do) and teachings. **Scripture** (`lore/scripture.ts`): verses of its scripture, one for each tenet, some for its doctrines and a few sayings, each cited by book, chapter and verse (or song and stanza where the lore is oral), in English and in its holy tongue, and written in that tongue's script. **Myths** (`lore/myths.ts`): how the world was made (by the word of one god, out of chaos, a cosmic egg, a slain giant's body, a great song, the earth-diver's mud, an emergence from the worlds below, the five suns, the separation of heaven and earth, and others, by archetype), how it will end (judgment, the doom of the gods, the turning of the wheel, the death of the sun), the road of the dead (by its burial doctrine and tenets), and legends of its prophet's calling and its holy mountains, lakes, groves, isles, relics and miracles. **Gods and sects:** its gods or holy figures, each with a story told from its domain (its birth, its kin among the gods, its deeds, what is sacred to it and what the faithful offer it; the life of a prophet or saint for a church or the faith of the prophets), and its branches, with where and among whom each arose. **Heads** (`lore/faith-heads.ts`): the line of its heads by its doctrine: high priests with their holy names (numbered as they repeat) and birth names for a faith with a head, the rulers of its holy realm for one led by sacred rulers, or the keepers of its chief shrine for one with no head, with how each came to office and how each left it, reaching back about a thousand years. **History:** founding, schisms and conversions in order. **Holy city** flies to its holiest place.

## Culture window (`components/CultureView.vue`, `lore/culture.ts`)

Click a culture on a realm's Overview (its **Culture**) or People tab, or search for one by name, to open a panel about that people. **Overview:** a short account (their numbers, the realms they rule, their outlook and traditions), their ethos and traditions with what each does, their customs and festivals (named in their language with the English meaning), their faith (and the one they kept before they converted; each opens the faith window), the realms they rule (each opens its details), kindred peoples (its language family), and the template and drift behind them. **Sounds:** the syllable structure, stress, tones or vowel harmony; consonant and vowel charts in IPA by place and manner (or height and backness) with each sound's spelling; spelling rules; and the respellings that turned the template's old forms into theirs. **Grammar:** the grammar in plain sentences, the pronouns and possessive pronouns (with "my house" and so on), how the people count (with a table of numbers), and example phrases and sentences with a word-by-word gloss. **Family:** its language family and proto-language, the sound changes since in order (each with an example, "\*aqua > acma ‘water’"), a table of words compared across the proto-language and up to five members (a dagger marks a word that replaced the inherited one; each sister opens in turn), and where older names in its lands come from. **Writing:** the people's script and what they call it, its letters or signs with their sounds, its numerals, their names and example phrases written in it, and sigils of their names. **Dictionary:** the core vocabulary with spelling, IPA, a rough English respelling (hidden on phones), noun class and the proto-form each inherited word comes from, searchable in English or in the language (any other English word is made on demand). **Translate:** type English and see it in the language, with how it is said (IPA with the language's stress, and a rough English respelling with the stressed syllable in capitals, "VAHR-skish"), glossed word by word, and written in the people's script (capitalized names you type stay as they are). **Homeland** flies to the culture's hearth.

## Search (`src/search/`, `components/SearchBar.vue`)

A search box at the top of the map (a search button on mobile) finds places by name or by kind. Press **/** or **Ctrl/Cmd+K** to jump to it, the arrow keys to move through the results and **Enter** to go; **Esc** clears it. Choosing a result flies there and rings the spot for a few seconds.

- **What it covers:** cities and towns (with population and layout), realms, cultures (choosing one opens the culture window), faiths (choosing one opens the faith window), continents, islands, seas, oceans, gulfs, bays, straits, lakes, rivers, mountain ranges, peaks, hills, forests, deserts, marshes, plains and named roads, all as soon as the world is generated. Sewers and catacombs are listed at their town from the start (and at their entrance once the town's plan has been drawn). Villages (and keeps, monasteries and camps), caves, glades, towers, crypts, ruins and mines are indexed by the towns worker in the background, whenever the view needs nothing else, nearest first, block by block (without their tracks, and without keeping them); a note shows its progress, which takes several minutes for a whole world. Quarters, districts and notable buildings (inns, taverns, smithies, temples and the rest) become searchable once their town or village plan has been drawn.
- **Matching:** exact names first, then names and words starting with the query, then names containing it; typing a kind ("cave", "crypt", "sewers", "inn", "lake", "keep") lists that kind nearest first. Ties go to the more important and then the nearer place. Filter chips narrow the results to settlements, water, regions, caves and dungeons, roads, or places in towns. Each result shows its kind, details (population, tags, "in Anterina"), and its distance and direction from the map centre.

## Caves and groves (`src/lairs/`)

Caves and glades are placed with the villages, per 1° block on a jittered ~30 km grid (`towns/manager.ts`), and drawn as map icons from zoom 8.6 with their names from zoom 10.4. They follow the **Settlements & roads** toggle.

- **Placement:** caves in hill and mountain country (more likely the higher the ground), in the face of the steepest slope within 1.5 km; glades in the forests (and now and then in riverside woods, scrub and savanna), on the most level ground within 900 m. Both keep clear of towns and villages.
- **Tags** come from the site: a size (small, medium or large); for caves, sealed (no way out), wet or flooded where it rains, dry in deserts; for glades, one or two features (a great tree, a pond, standing stones, a stream (likelier by a river), a camp, ruins, rocks, flowers), and dry in arid or hot country (no water, yellowed grass and crowns).
- **Names** (`names/names.ts`, `lairName`) use the local culture's proper names (now and then an English compound, as in Watabou's "Starbog") with a noun that fits the size, water or feature (Hole, Grotto, Caverns, Catacombs, Halls; Glade, Dell, Glen, Stones, Pool, Oak), plus a few culture-specific nouns (dwarven Delve and Deeps, Elvish Bower, Celtic Nemeton). Descriptive forms appear too: "the Dripping Grotto", "the Troll's Den", "Glade of Whispers".
- **Caves** (`lair.ts`), Chambers of two or three overlapping round halls joined by a spanning tree of winding passages (plus the odd loop), stamped into a field, roughened with noise and traced as smooth walls by marching squares; specks and small pockets are cleaned up. Unless sealed, one or two passages run off the map edge as entrances. Pools fill low noise hollows in wet and flooded caves; boulders sit near the walls, stalagmites stand in clusters.
- **Cave levels:** small caves have one or two levels, medium up to three, large two to four (a tag such as "3 levels"). Each level has its own chambers and passages on the same footprint; only the top level has entrances, and deeper levels grow wetter. The ways down (carved stairs, a shaft with a rope ladder, or a steep scree slope) sit in chambers far from the entrance, clear of pools and boulders, and open into a chamber at the same spot on the level below, where the way up is marked in the same style; large caves sometimes have two ways down. Openings are drawn dark, the foot of a way up light, each with a caption ("Down to level 2").
- **Cave key:** chambers are numbered through every level from the way in, each with a heading and description chosen from what it holds: the cave mouth, the way down and the foot of the way up, pool chambers, great caverns (the largest fifth), stalagmite halls, grottoes (the smallest third) and plain chambers. Caves have an adventure hook, and their chambers carry creatures, hazards and treasure as in the dungeons.
- **Groves** (glades on the map): two to five noise-warped clearings (by size) in a forest of tree crowns packed on a jittered grid, joined by winding trodden paths (a spanning tree, a loop in larger groves, and a path in from the map edge, marked with an arrow). Each clearing has its own feature: the site's tags first, then a pick from the rest: a great tree, a hollow tree, standing stones (sometimes round an altar stone), a pond, a spring ringed with stones, a shrine heaped with offerings, a druid's hut, a camp, ruined walls (sometimes with a well), boulders or a flowering meadow. A stream may cross the grove, with a ford where it meets a path. Grass tufts fill the open ground; crowns keep off the paths.
- **Grove key:** clearings are numbered from the way in; the view lists an adventure hook and a heading and description for each (the ford too), with creatures, hazards and treasure as in the dungeons. A **hollow tree** opens on a second level, the hollow among its roots, reached by a rope down the split trunk: a round chamber with two or three root tunnels to smaller hollows (a hoard, a nest, a seep), numbered on from the grove.
- **Near special features:** in a mushroom forest most lairs are glades, grown with toadstools in place of flowers (tags "fungal", "mushrooms"); on volcanic ground, ash, lava and in canyons caves are likelier (tags "volcanic", "canyon"), and a volcanic cave runs with lava where others hold water.
- **Mushroom and cursed groves:** a grove in a mushroom forest is drawn under giant mushroom caps (muted violets, slate blues and greens, now and then a bright one, with pale spots and a sheen) over a violet, mossy floor; its great tree is a great mushroom, its hollow tree a hollow stalk, its meadow a toadstool ring, its hut a spore-witch's, with hooks of its own. A grove in a cursed wood has grey, dying crowns with bare limbs showing through, grey grass, and a dead tree, a black pool, a bitter spring or a defiled shrine in its key. Both have their own map icons.
- **Mountain passes** (`pass.ts`): where a road crosses a range (the highest point of the road for 15 km either way, with a climb of 300 m or more on both sides within 50 km, above 1,100 m, at least 30 km from the next), a pass is marked with its own icon and opened like a cave. Its map lies the way the road runs over the ground: the trail enters from one edge, climbs by two to four switchbacks across a slope of scree to the saddle, and runs down to the far edge, on a shelf of pale stony ground between cliffs drawn with hachures (or wooded slopes, on a forested pass). A stream crosses the climb on a rope bridge over a gorge or at a ford; there is a waystation (a stone hut with a fire) or a wayside shrine on a ledge, a cairn on the saddle, and sometimes a tunnel through a spur, a ruined watchtower on a knoll, or a rockfall across the way. Passes above 2,600 m, or where the warmest month stays below 9 °C, lie under snow, with texts of their own. The key runs from the way up to the way down, with a hook (bandits on the saddle, a toll-keeper, a caravan lost, the first snows) and creatures, hazards and treasure of the mountains.
- **Drawing** (`render.ts`): caves in ink on parchment, with a rock band and Watabou-style hatching (groups of short parallel strokes) round the walls, a 5 ft grid on the floor, pools, boulders and entrance arrows; glades with scalloped crowns sharing one inked outline, shadows and highlights, a 5 ft grid over the clearing, standing stones, tents and campfire, broken walls and water.
- **Views** (`view.ts`, `components/LairView.vue`): hovering an icon or name shows a card with the name, tags and a miniature; from about zoom 17, once the map is more than ~170 px wide on screen, hovering lays the map over the ground at its true size instead (with a faded rim). Double-click (or tap twice) to open the full view, with a tab per level (the arrow keys, or clicking a way up or down, also change level), Grid and Labels toggles, a north arrow, a scale bar and **Download PNG**; caves and groves show their key beside the map (below it on phones), and their PNG includes the title, hook and key. **Leave** or Esc returns to the map.

## The Underworld (`gen/underworld.ts`, `lairs/deep.ts`, `components/under-style.ts`)

With **Fantasy races** on, a network of caverns and tunnels lies below the continents, made after everything else on random streams of its own (so nothing on the surface changes). It is shown by the **Underworld** map layer, which draws the surface dark and faint and hides its towns, borders and lettering.

- **The upper deep:** a dwarven hall below every delve (no two within 300 km; named after the delve: "the Halls of …", "… Deephall", "the Deep Gate of …"), then great caverns, underground lakes, fungal forests (most of all under the mushroom forests and in wet, warm country), chasms and the lost or sealed halls of a people long gone (with no delve above), mostly under mountains and hills, at least 330 km apart (30 to 140 by land area).
- **The lower deep:** sunless seas (110 to 250 km across), burning rifts (most of all under volcanic ground), the fallen cities of a forgotten people, vast fungal forests and abysses, at least 700 km apart (8 to 40).
- **Tunnels:** on each tier a relative-neighbourhood graph (no tunnel where a third cavern lies nearer both ends; at most 700 km in the upper deep and 1,300 km in the lower), with the remaining parts joined by their shortest links. Tunnels between dwarven halls are built **deep roads**, named ("the Deep Road of …", "the Iron Road Below"). Every cavern of the lower deep is reached by a **great shaft** from the nearest cavern above.
- **Ways in:** every delve's deep road leads down to the nearest hall (the location title says where, and links to it); about three in five active or dormant volcanoes have a lava tube down to a cavern within 350 km; and about half the caverns with no way in have a **sinkhole** 30 to 140 km away on the surface (a named place with its own icon, away from towns). Some large caves of three or four levels near a cavern of the upper deep (within 150 km) go down to it: their last chamber becomes "the way into the deep", and their hook says where it leads.
- **On the map:** caverns are glowing shapes coloured by kind (the lower deep fainter, beneath the upper), marked by dots when zoomed out; tunnels are dashed lines (amber for the upper deep, violet for the lower), deep roads solid gold, shafts dotted with rings at both ends, and the ways in pale rings with their names. Hovering tells what lies below ("Below: the Sunless Sea of … (sunless sea, lower deep)"). Search lists every cavern and deep road and switches to the layer.
- **Cavern maps** (`deep.ts`): clicking a cavern opens the heart of it as a cave map on a larger scale (120 to 156 m across): a great hall of rock of several lobes, with a tunnel running off the map toward each cavern it joins, and a shaft up to the surface or the upper deep and down to the lower deep, each captioned with where it leads. What fills it follows its kind: a great cavern of columns, crystal clusters and a pool; a forest of glowing giant fungi; a lake with an island; the harbour on the shore of a sunless sea; a river of lava under a stone bridge, with a forge; the gridded streets, roofless houses and stepped temple of a fallen city; a square-cut dwarven hall with rows of pillars and a throne; or a chasm or abyss crossed by a rope or stone bridge. The key names each tunnel's destination, the shafts and the cavern's features, with a hook and creatures, hazards and treasure of the deep.
- **Moving between the surface and the deep:** on a cavern map, clicking a tunnel mouth or a way down opens the cavern it leads to (switching to the Underworld layer and flying there), and clicking a way up to the surface switches back to the fantasy map and flies to the entrance; hovering one names its destination. From the surface, clicking a sinkhole opens the cavern below it, the last chamber of a cave that goes down ("the way into the deep") does the same, and a delve's dungeon view has a **Deep gate** button that opens the hall below it.

## Peoples and realms of the deep (`gen/deep-peoples.ts`, `components/DeepRealmView.vue`)

With the Underworld come four peoples of its own, culture templates with `world: 'deep'` (`names/bundles/shadowelf.ts`, `deepgnome.ts`, `fungusfolk.ts`, `greydwarf.ts`). They are added to the world's cultures after the surface's (so no surface culture, language, faith or name changes), each with a language, a script and numbers, and faiths of their own: the **shadow elves** (a veiled faith of the spider and the dark, ruled by priestesses and matron mothers), the **deep gnomes** (spirits of stone and gem), the **fungus folk** (the mycelium, a shared mind of spores) and the **grey dwarves** (iron-bound ancestor worship, with slaves at the forges).

- **Hearths and spread:** each people takes one to three hearths (the shadow elves one more) in the caverns that suit it best (the elves the fallen cities, lakes and sunless seas, the gnomes chasms and great caverns, the fungus folk the fungal forests, the grey dwarves the lost halls), then spreads along the tunnels by cost of travel and how well each cavern suits it. Delve halls, abysses and the burning rifts of the lower deep stay unsettled; in a typical world about a fifth of the caverns are settled.
- **Cities:** every settled cavern is a city of its people with a name in their tongue (sometimes with its meaning, "Khok (Sootpit)"), a size and a kind (a city, a warren, a ring of the fungus folk, an iron hold), the largest of each realm its capital.
- **Realms:** every shadow elf city is a realm of its own under a matron mother; the other peoples join neighbouring cities into realms of up to five (eight for grey dwarves). Each realm has a ruler and house, a name in its people's style, a government, arms, relations with its neighbours (war, feud, raids, truce, peace, trade or alliance) and with the dwarven delves it touches, and a chronicle (its founding, wars and alliances, slave revolts, horrors and the present ruler's accession).
- **Nameless horrors:** about three in four abysses and lower rifts hold something without a name ("the Hungering Dark", "the Eye Below", "the Mother of Maggots"), shown on the map with its own mark and lettering, keyed on its cavern map and remembered in the chronicles of the realms near it.
- **On the map:** realm lands are washed and ringed in their colour (neighbours never share one), cities are marked with towers, and realm names and horrors are lettered. Clicking a realm's name opens its **realm window**: arms, people, faith, government and ruler, its cities (each opening its map), neighbours and delves with their relations (each clickable) and its chronicle. Search lists deep cities, realms and peoples ("People of the deep"); hovering names the city, realm and any horror below.
- **City maps** (`lairs/deep.ts`): a settled cavern's map is a city of its people: spires and a temple of the spider for the shadow elves, burrows, workshops and a gem market for the gnomes, spore farms and a great ring for the fungus folk, and the iron hall, forges and slave pens of the grey dwarves, with a key naming its ruler and places, and hooks of their own.
- **Delves:** the dwarven delves of the surface are unchanged; each gains a deep gate to the hall below it, and its location title gives its relations with the nearest deep realm ("Deep road down to …, trading with …").

## Abandoned villages (`towns/manager.ts`, `towns/village.ts`)

- **Placement:** about one 1° block in four has an abandoned village, on habitable Old World land away from towns, villages, caves and glades (placed after them, so they keep their places and names), and the village at the heart of a cursed land is one too.
- **Cause:** from its surroundings: ash (on volcanic ground), a curse (in a cursed land), a flood (by a river), drought (in dry country), or otherwise plague, war, famine, raiders or (in fantasy worlds) a dragon, from five to four hundred years ago. Each has a short tale ("The plague came to … 120 years ago. The dead were buried in a pit beyond the chapel…") and a line of what is said of it now.
- **Plan:** laid out by the village generator as what it was (a farming village, a mining or logging camp), then aged: every house roofless or collapsed (more of them heaps after a war, a dragon or ash), the fields gone back to the wild with only their hedgerows left, no stalls or boats, and trees grown up among the houses; the chapel becomes "the Ruined Chapel" (or "the Burnt Chapel"), the mill "the Old Mill". Its buildings cannot be entered.
- **On the map** it is marked by a ruined-houses icon from zoom 8.6 instead of a village dot. The icon opens its ruin (the manor or chapel, with cellars) or, after a plague or a curse, its crypt, as a dungeon whose key begins with the village's story. The location title gives the cause and when ("Abandoned village · emptied by plague · 120 years ago"), and search lists it.

## Dungeons (`src/dungeons/`)

Dungeons are a grid of 5 ft squares (`core.ts`) carved into rooms and corridors, with doors (open arches, doors, locked doors, secret doors, portcullises, bars), furniture, numbered rooms and a written key, on one or more levels joined by stairs, ladders, shafts or a spiral stair. Each way down opens at the same spot on the level below, in a room far from the way in.

- **Kinds** (`kinds.ts`):
  - **Mines** (1 to 4 levels): a main drift from the adit with rails and timber supports, wandering cross-cuts ending in stopes (worked chambers with ore, flooded workings, a miners' camp, a collapse), and a shaft between levels.
  - **Towers** (2 to 5 floors, a cellar half the time, and the roof): round floors of the same plan, with a spiral stair in the same place on every floor, one or two partitions with doors, rooms furnished by use (guard room, store, hall, library, study, bedchamber, laboratory, armoury, chapel; cells and a cistern below), arrow slits, a door in the ground floor wall and a crenellated roof with a beacon.
  - **Crypts** (1 to 3 levels): rooms mirrored about a central axis, a pillared hall on the axis with a statue or altar, burial vaults lined with sarcophagi, ossuaries stacked with skulls, chapels, a treasury and a guard room, and burial niches along the passages.
  - **Ruins** (1 to 3 levels): a roofless building of a hall and wings, cut into rooms whose walls have broken away in runs (rubble where they fell), collapsed floors, trees and bushes around and within; larger ruins have cellars below.
  - **Delves**: the halls of a dwarven city behind its great gate, "the Halls of X", "the Deeps of X" or "the Delve of X", in as many **districts** as its people need (`delveDistricts` in `core.ts`: one for every 2,800 people or so, up to fourteen; a delve of 33,000 has twelve). The first holds the market and the hall of the ancestors, about one in three are forge districts ("the Smiths' Deep", "the Foundries"), the larger delves have a market quarter and a district of the ancestors' tombs, and the rest are the halls of the clans ("the Halls of Clan Ironbrow"). The delve opens on its **overview** (not to scale): the great gate and the gate hall, the great avenue lined with statues, and each district a block on it that leads to the district's own map, with a passage at the west end of every map back to the overview. Then come the gate halls, one map for each district, and the deeps below the first forge district. Each map has a pillared great hall at its heart, a broad avenue across it lined with statues of the ancestors, and two cross avenues, with the level's rooms opening off them: in the **gate halls** (entered from the gate) the gate hall, the king's hall with its throne, guard rooms, the wardens' barracks, storerooms, a brewery and pony stables; in **the great halls** the market hall, the hall of the ancestors, an alehouse, the moot hall and many homes; in a **forge district** forges, smelters, an armoury, the clan vault behind a locked door, storerooms and the smiths' homes; in a **clan district** the clan hall, some twenty homes, an alehouse, an ancestor shrine, a brewery and storerooms; in the **market vaults** two market halls, alehouses, storerooms and a strongroom; in the **halls of the ancestors** the great hall of the ancestors, the tombs of the kings and shrines (a delve of one district mixes the halls and the forges). The lowest level is **the deeps**: mine drifts, stopes and ore faces, and one working the dwarves walled up and locked. The key names who is about (wardens, smiths, merchants, loremasters, a duergar spy), dwarven traps, treasure and sounds, with hooks of their own.
  - **Catacombs** (1 to 3 levels): a maze of narrow galleries (a randomised depth-first maze on a 4-square lattice, with extra openings), lined with niches (some still holding skulls), opening into ossuaries, burial chapels, vaults and shrines.
  - **Below the well** (1 or 2 levels): about one village well in nine leads down (`secretWell` in `towns/village.ts`). The shaft drops into a pool in a natural grotto; winding passages of living rock lead to further caves (pools in the wet ones); and behind a secret door off the furthest cave lies a worked chamber someone keeps hidden: a smugglers' cache, a hidden shrine, or a forgotten hoard. A second level holds hidden vaults. Its creatures, traps and treasure are those of the natural caves.
  - **Sewers** (1 or 2 levels): built from the town plan around the grate. The main tunnels follow the streets near it in straight runs (a water channel with a walkway either side), drains branch off under the lanes, junction chambers mark where tunnels cross, and side rooms (cisterns, stores, dens, a shrine, a collapse) open off the walkways; where a river or the sea lies within 150 m (further under larger towns), a trunk runs out to a barred outfall. Half of each city's sewers have a cistern level below. A town has one sewer; a city has two to four separate ones (`sewerCount`: two, three from 15,000 people, four from 30,000), each draining its own quarter of the city in a different direction from the centre and named for it ("the North Sewers of X"), with its main grate on the street nearest the middle of that quarter and kept well clear of the others. Each map grows with the town (`sewerScale`): 96 × 72 m under a small town, 1.25 times that under a town of 8,000, and from 1.3 to 1.8 times (up to about 173 × 130 m) for each of a city's sewers; each city sewer has two or three grates down from the streets (towns of 6,000 or more two), each marked on the plan and each opening that sewer. Under most cities (in one of their sewers, about 85% of cities) and some large towns the **thieves' guild** hides off a quiet tunnel far from the main grate: a passage ending at a secret door, then the guildhall, a locked vault of loot and blackmail, and the thieves' quarters. Under a thieves' city the guild is always there, with a fences' market and the guildmaster's rooms besides.
- **Key** (`key.ts`, with `keys/flavour.ts`): an adventure hook for the site, often with a reward or a complication, and, for each numbered room, a heading and a description drawn from what the generator placed there (no description repeats within a site while others are left; burial vaults sometimes carry an epitaph), the way down where there is one, and now and then a detail for the senses. Rooms may also note a **creature**, a **trap** or a **treasure**, chosen for the kind of site: entrances are quieter, guard rooms and dens likelier to be occupied, treasuries always hold something, and deeper levels are more dangerous and richer. No note repeats within a site.
- **Drawing** (`render.ts`): hatched rock (or open ground, for ruins and roofs), pale floors with a drop shadow on a 5 ft grid, thick ink walls, doors set in the walls, water with ripples, rubble, rails and furniture (sarcophagi, pillars, niches, altars, statues, chests, barrels, crates, bones and skulls, beds, tables, bookcases, braziers, a throne, a well, carts and ore), ways up and down captioned with the level they lead to, entrance arrows and room numbers placed clear of stairs and furniture.
- **Placement** (`towns/manager.ts`): towers, crypts and ruins on a jittered ~45 km grid per 1° block, kept clear of towns, villages, caves and groves (towers on rises, more often in hill country; crypts and ruins on gentle ground), with a size and a number of levels or floors; a **mine** under every mining camp, entered at the mouth of the camp's first adit and marked there on the camp's plan (searchable at the camp until the plan is drawn), named after the camp; the way down a village's **secret well**, marked at the well on its plan. **Sewers** lie under every city and every town of 4,000 or more, with a grate drawn on the plan on a main street near the centre; **catacombs** under every city and about half the towns, with a stair in the graveyard, by the temple, or in the market (`townUnderground` in `core.ts`). Names (`dungeonName` in `names/names.ts`) use the local culture: "Ashcombe Tower", "the Sunken Crypt", "the Witch's Spire", "the Sewers of Makaba".
- **Views** (`view.ts`, `components/DungeonView.vue`): standalone sites show icons from zoom 8.6 (a tower, a tomb, broken walls, crossed picks) and names from zoom 10.4; grates, catacomb stairs, mine adits and secret wells show on town, camp and village plans from zoom 13.6, with names from zoom 15.2. Hovering shows a card with a miniature of the way in; double-click (or tap twice) opens the dungeon: a tab per level (opening on the way in, so a tower opens on its ground floor), Grid and Numbers toggles, the map, and the hook and key beside it (below it on phones). Clicking a stair (or a delve's passage) goes to its level; the arrow keys change level too. The map **zooms** with the mouse wheel, a pinch or the − / Fit / + buttons (up to eight times), and **pans** by dragging; clicking a room's name in the key zooms in on that room. Each new level opens fitted to the screen. **Download PNG** saves the whole level shown, at full size, as a page with the title, hook, map and key; **Leave** or Esc returns to the map.

## Climate tuning against Earth

`tuning/climate/` scores the climate model on real Earth. It runs the generator's climate pipeline on WorldClim 2.1 elevation (the `heightmap` option of `generateWorld` skips tectonics and erosion) and compares the result with observed WorldClim monthly climatology (1970–2000).

```sh
npm run earth:fetch                      # once: downloads ~46 MB to tuning/data/ (git-ignored)
npm run earth:eval                       # score current parameters against tuning/climate/baseline.json
npm run earth:eval -- --update-baseline  # accept a new score
npm run earth:eval -- --res=512          # faster, coarser
```

- **Reference map:** the observed monthly data is reduced to the same inputs the simulation produces (mean, warmest and coldest month temperature, summer/winter precipitation) and classified with the same Köppen code. Differences therefore measure the simulation, not the classifier.
- **Reported metrics** (area-weighted over land):
  - exact Köppen class accuracy
  - main-group (A–E) accuracy and Cohen's kappa
  - annual, warmest-month and coldest-month temperature RMSE
  - precipitation log error and bias
  - summer-rain-share error
  - group shares and a confusion matrix
- **Objective:** these combine into one `OBJECTIVE` (0–1, higher is better). The command exits non-zero if it regresses against the baseline.
- **Maps:** written to `out/earth/koppen-{observed,simulated,agreement}.png`. In the agreement map, green is the same class, yellow the same group, and red a different group.

After any change to climate code or `CLIMATE`/`KOPPEN` constants, run `npm run earth:eval` and make sure the objective did not regress. Data: Fick & Hijmans (2017), WorldClim 2.1, CC BY 4.0.
